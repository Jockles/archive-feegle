This chapter goes through the CSS for the Instagram posts and DMs in the last chapter. Posts (ig) sit in the feed (ig-feed), and they're the interesting part, with the clickable like and save buttons and the icons drawn in CSS. DMs (igdm) are built like iMessage, so they're quick. At the end there's a section on switching parts of every post off for your whole fic, without editing each one.

Each part starts with the CSS itself and a line or two on what it does. The Options boxes show what you can safely change, and the How it works boxes go through the rules a line at a time, if you want to learn how it's put together. The longest bits of CSS are folded away in boxes of their own.

13.1 Getting the CSS

The Instagram CSS is here: jockles.com/fic/megaskin/css/instagram.css. It needs the core CSS too, so paste the core into your work skin first and this underneath it.

13.2 How the Module is Laid Out

The usual order - the main rules, Links, Dark theme and Auto theme - with a Scrolling section before the themes, like Twitter/X, and Icons at the end. A post has no mob-body, so the core's scrolling doesn't reach it, and it gets its own.

The feed is the default container, so it comes first.

How it works: making the posts into one feed

A post inside an ig-feed drops its own width, border, rounded corners and scrolling, so the posts sit one after another and only the feed scrolls. The last post keeps only a small gap under it, so a feed with one post fits snugly. Its background is transparent and its colour is inherit, which is how the posts take the feed's theme. The Stories row is a flex row with overflow: hidden, so any circles that don't fit are cut off at the edge.

How it works: the rings on the Stories circles

The ring is drawn by ::before: a gradient circle, set behind the picture with position: absolute. The picture sits on top, slightly smaller, with a border in the background colour, which makes the gap between the picture and the ring. Drawing the ring separately means the colour classes for initials still work on the ig-pfp. close swaps the gradient for green, and plain hides the ring. The + badge on your own circle is an ::after on the me story, a small circle placed over the bottom right of the picture.

13.4.2 Clickable Buttons

This is the part that comes from mystyrust's fic chat, is this real? (see the credits). There's no way to run a script on AO3, so nothing can react to a click - except the <details> tag. A details tag is a box that opens and closes when you click its <summary>, and when it's open, the browser gives it an open attribute. CSS can see that, so it can show one thing when it's closed and another when it's open:

#workskin .ig .ig-tog summary {
  display: inline-block;
  list-style: none;
  cursor: pointer;
  color: inherit;
}

#workskin .ig .ig-tog summary::-webkit-details-marker { display: none; }

#workskin .ig .ig-tog summary::marker { content: ""; }

#workskin .ig .ig-tog .on { display: none; }

#workskin .ig .ig-tog[open] .on { display: inline; }

#workskin .ig .ig-tog[open] .off { display: none; }
How it works: the rules, one at a time
  • The first three rules hide the little triangle that every details tag has, in every browser - Chrome and Safari call it one thing, Firefox another, so it takes three goes.
  • Then: on parts are hidden. [open] means "when it's been clicked open", so once it's clicked, the on parts show and the off parts hide. Click again, the box closes, and it swaps back.
  • Everything lives inside the summary, which is the part that's always visible, so nothing ever actually opens - it just swaps.
#workskin .ig .ig-stat.right {
  float: right;
  margin-right: 0;
}

#workskin .ig .ig-stat.liked .ic.ic-heart,
#workskin .ig .ig-tog[open] .ic.ic-heart { background-image: url(https://images.squidge.org/images/2026/11/15/heart-filled-red.png); }

13.4.3 Liked By, With Faces

#workskin .ig .ig-like-pfp {
  display: inline-block;
  position: relative;
  box-sizing: content-box;
  width: 18px;
  height: 18px;
  margin-left: -8px;
  border: 2px solid #ffffff;
  border-radius: 50%;
  overflow: hidden;
  vertical-align: middle;
}

#workskin .ig .ig-like-pfp:first-child { margin-left: 0; }

Each face is a tiny circle with a white edge, and the negative left margin pulls each one 8px back over the one before, so they overlap.

How it works: keeping each face's edge on top

The first one doesn't need pulling back. position: relative keeps each face's edge on top of the picture before it: the picture inside a pfp span is placed with position, and without it the pictures would be drawn over every edge. This is why the faces have to be on one line of code with no gaps: a space between two inline things takes up room, and would push them apart again.

13.5.2 Square and Tall Photos

The shape comes from aspect-ratio: 1 for square, and 0.75 (3 wide by 4 high) for tall.

#workskin .ig .ig-photo.square,
#workskin .ig .ig-photo.portrait {
  display: flex;
  align-items: center;
  justify-content: center;
  box-sizing: border-box;
  overflow: hidden;
}

#workskin .ig .ig-photo.square { aspect-ratio: 1; }

#workskin .ig .ig-photo.portrait { aspect-ratio: 0.75; }

#workskin .ig .ig-photo.square img,
#workskin .ig .ig-photo.portrait img {
  position: absolute;
  top: 50%;
  left: 0;
  width: 100%;
  height: auto;
  max-width: none;
  transform: translateY(-50%);
}

#workskin .ig .ig-photo.square img.landscape,
#workskin .ig .ig-photo.portrait img.landscape {
  top: 0;
  left: 50%;
  width: auto;
  height: 100%;
  transform: translateX(-50%);
}
How it works: cutting the picture to fit

AO3 only keeps a plain number here, so write it as one number rather than 3 / 4. The box hides anything that spills out. The picture inside is taken out of the line with position: absolute, made as wide as the box and moved up by half its own height with transform, so the middle of it shows. A landscape picture is made as tall as the box and moved left instead. Described photos are centred in the box with flex.

How it works: sliding the photos in

Every photo after the first sits inside a <summary>, parked just off the right-hand edge with left: 100%, and the carousel's overflow: hidden keeps it out of sight. When its details opens, left changes to 0, and the transition makes it slide in over the photo before it. Close it and it slides back out. Each details sits inside the one before, so the next arrow only shows once you've got to that photo.

How it works: the arrows, the counter and the dots

The arrow is the summary's ::before: a white circle at the right, which moves to the left and turns round once it's open, so the same arrow takes you back. The ig-carousel-info line lies over the whole photo, so tapping the photo itself does nothing, and holds the counter at the top right and the dots. The carousel has 24px of padding at the bottom, and the dots sit in that gap underneath the photo, like on Instagram. The photos after the first stop at bottom: 24px so they don't cover it, and the arrows move up a bit to stay in the middle of the photo. The dots are light grey (#c7c7c7) in light mode and dark grey (#555555) in dark mode, with the current one blue (#0095f6).

How it works: the icon on the photo

Closed, the summary is the icon: a dark see-through circle pulled up into the bottom left corner of the photo with a negative top margin, with a round head (::before) and shoulders (::after) in white. It's the same in light and dark mode. After a carousel it's pulled up further, past the dots, so it still sits on the photo. The title inside it is hidden until it's open. The post gets position: relative so the sheet can be placed inside it.

How it works: the open list

Once it's open, the summary moves up to the top of the sheet, the head turns into the grey grab bar and the title shows, so clicking the top of the sheet closes it again. It has the same solid background as the sheet, so a long list scrolls away underneath it instead of showing through. The sheet is placed over the bottom 85% of the post with rounded top corners. Its huge see-through shadow darkens the rest of the post, and the post's overflow: hidden stops the shadow spilling out. The sheet is white in light mode and dark grey (#262626) in dark mode. Each person line is the picture floated left, the username and the grey name underneath, with the button floated right.

How it works: stretching a short post

A short post doesn't leave the list much room, so while it's open the ig-tagged block turns into an invisible float, 300px tall and no width, just under the photo. The post has to stretch to hold it, so a short post grows and a long one stays the same. Posts in a feed get display: flow-root, which makes them hold floats.

13.6.2 The Stories Ring

The stories ring is three layers.

How it works: the three layers

The circle gets 2px of padding with Instagram's rainbow gradient behind it, so the gradient shows as a ring around the edge. Then the picture inside gets a 2px white border, which makes the gap between the ring and the photo. 45deg sets the direction of the gradient, corner to corner, and the percentages say where each colour sits. In the dark theme, the white gap turns the same dark colour as the post.

Only two pictures fit in the circle, so if a third one sneaks in, it's hidden.

How it works: placing the two pictures

Both pictures are taken out of the line with position: absolute: the first goes to the top right and the second to the bottom left, where it comes out in front because it's later in the HTML. The front one has a 2px border in the background colour (white in light mode, nearly black in dark mode), which makes the gap between the two circles. ig-and undoes the bold and the small grey line that every span in the account line gets otherwise.

13.8 Links, Scrolling and Themes

#workskin .ig .fake-link, #workskin .ig a:not(.tl) { color: #00376b; }

#workskin .ig {
  max-height: 700px;
  overflow-y: auto;
  overflow-x: hidden;
}

Links and hashtags in posts are Instagram's dark blue.

How it works: scrolling a feed, and a post on its own

A feed scrolls once it's taller than 580px, the same height as every other chat, and the posts inside it don't scroll on their own. A post on its own scrolls as a whole once it's taller than 700px, which is why a post on its own with a real photo needs no-scroll. The feed's height rule is just as strong as the core's no-scroll rule and comes after it, so the feed has its own no-scroll rule too:

#workskin .ig.ig-feed { max-height: 580px; }

#workskin .ig.ig-feed.no-scroll { max-height: none; overflow-y: visible; }

The dark theme is Instagram's very dark blue-black, #0c1014, with #f5f5f5 text and #a8a8a8 grey.

How it works: the white edges in the dark theme

It also turns the white edges dark - the gap in the story ring and the edges of the liked-by faces - because a white edge on a dark post would show. The auto theme is the same rules again inside @media (prefers-color-scheme: dark).

13.9 Switching Parts Off for the Whole Fic

You can leave anything out of a single post's HTML. But if you never want something on any post, it's quicker to switch it off once in the CSS. Paste any of these at the very bottom of your work skin - below everything else, so they win:

/* no Follow links */
#workskin .ig .ig-top .ig-follow { display: none; }

/* no menu */
#workskin .ig .ig-top .ig-menu { display: none; }

/* no verified ticks */
#workskin .ig .ig-top .ig-tick,
#workskin .ig .ig-person .ig-tick { display: none; }

/* no stories rings */
#workskin .ig .ig-top .ig-pfp.story { padding: 0; background: none; }
#workskin .ig .ig-top .ig-pfp.story .pfp { border: 0; }

/* no "View all comments" lines */
#workskin .ig .ig-view-all { display: none; }

/* the time in capitals, like older Instagram */
#workskin .ig .ig-time { text-transform: uppercase; font-size: 0.7em; }
How it works: why the counts line has the class three times

The clickable heart has its own rule that shows its on count once it's clicked, and that rule is quite specific. Repeating the class makes this rule more specific still, so the count stays hidden after a click too - the same trick as hide in the core.

Readers with the workskin switched off will still see anything you've switched off this way, because it's still in your HTML. That's usually what you want - a "Follow" or a count doesn't hurt anyone - but if it isn't, leave it out of the HTML instead.

13.10 Taking Parts Out

To make your skin shorter, search for the class names and delete every rule with them in, including in the dark and auto blocks:

  • DMs: everything starting .igdm.
  • The top bar and Stories row: ig-header, ig-add, ig-logo, ig-notif, ig-badge, ig-stories, ig-story and ig-story-name. Keep the ig-feed rules, because they hold the posts.
  • Clickable buttons: ig-tog, and the .on and .off rules. Keep ig-stat for plain buttons.
  • Liked-by faces: liked-by, ig-like-pfps and ig-like-pfp.
  • Stories ring: the two .story rules.
  • Account line extras: ig-menu, ig-tick, ig-follow (and its btn rules) each come out on their own.
