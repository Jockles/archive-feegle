This chapter goes through the CSS for the Tumblr posts in the last chapter: the card, the header with its picture and checkmarks, reblog chains, asks, quote and chat posts, the bottom row, and the feed behind the cards.

Each part starts with the CSS itself and a line or two on what it does. The Options boxes show what you can safely change, and the How it works boxes go through the rules a line at a time, if you want to learn how it's put together.

15.1 Getting the CSS

The Tumblr CSS is here: jockles.com/fic/megaskin/css/tumblr.css. It needs the core CSS too, so paste the core into your work skin first and this underneath it.

15.2 How the Module is Laid Out

The usual order - the main rules, Links, Scrolling, Dark theme, Auto theme and Icons. Like a tweet or an Instagram post, a Tumblr post has no mob-body, so it scrolls as a whole once it's taller than 700px.

15.3 The Container

15.3.1 The Card

#workskin .tb {
  background: #ffffff;
  color: #000000;
  border: 1px solid #e3e3e3;
  border-radius: 14px;
  overflow: hidden;
  font-family: "Helvetica Neue", Helvetica, Arial, sans-serif;
  line-height: 1.5;
}

#workskin .tb .tb-text { display: block; padding: 0.3em 0 0.8em 0; }

#workskin .tb .tb-text p { margin: 0.5em 0; padding: 0 0.9em; }

A white card with rounded corners, like the mobile app.

How it works: taller lines and paragraph gaps

Tumblr posts are more spaced out than chats, so the lines are taller (1.5), and paragraphs in the body get their gaps back - the core takes them away from every chat, but a post needs them.

#workskin .tb :not(.pfp) > img {
  display: block;
  max-width: 92%;
  height: auto;
  margin: 0.6em auto;
  border-radius: 4px;
}

This one catches every picture in a post, but not profile pictures.

How it works: every picture except profile pictures

:not(.pfp) > img means "a picture whose box isn't a pfp". The picture is centred, with a little space either side, and never wider than the card.

15.3.2 Header

15.3.2.1 The Header
#workskin .tb .tb-top,
#workskin .tb .tb-blog {
  display: block;
  overflow: hidden;
  padding: 0.8em 0.9em 0.3em 0.9em;
  font-weight: normal;
}

#workskin .tb .tb-top { padding-bottom: 0.8em; border-bottom: 1px solid #eeeeee; }

#workskin .tb .tb-name { display: block; min-height: 38px; margin-left: 48px; overflow: hidden; }

#workskin .tb .tb-name > b { display: block; overflow: hidden; white-space: nowrap; font-weight: bold; line-height: 1.3; }

#workskin .tb .tb-name > b:only-child { line-height: 38px; }

#workskin .tb .tb-detail { display: block; font-size: 0.85em; color: #6c7a8b; }

The post's header (tb-top) and each reblog's header (tb-blog) are built the same, except the post's header has a line under it.

How it works: the picture, the name and long names
  • The picture floats left, and the name is pushed 48px in from the left to clear it - the picture's 38px and a gap. min-height makes the name block at least as tall as the picture, so the next thing always starts below both.
  • :only-child catches a name with no grey line under it, and makes its line as tall as the picture, which centres it from top to bottom beside the picture.
  • The name never wraps onto a second line (nowrap), and overflow: hidden on both cuts off anything that doesn't fit. That's for blogs with lots of checkmarks: like the app, they run up to the Follow button or the three dots and get cut off sharply there, however wide the screen is.

The header code is written over several lines, and AO3 turns line breaks into <br /> tags, so a couple of rules hide those and flatten the paragraph AO3 wraps around it, as in WhatsApp's message bar.

How it works: the right-hand side, Follow and the three dots 
#workskin .tb .tb-follow { display: block; float: right; margin: 2px 0 0 0.5em; }

#workskin .tb .tb-menu {
  display: block;
  float: right;
  height: 38px;
  line-height: 38px;
  margin: 0 0 0 0.6em;
  color: #777777;
  letter-spacing: 0.05em;
  font-size: 0.8em;
}

Both float right, which is why they come before the name in the code (see The Account Line Extras). The first one in the code goes furthest right, so the dots go first and the Follow button second, to end up in the right order.

These are the checkmarks drawn with CSS. Every checkmark starts blue, and each one after it gets the next colour along.

How it works: counting the checkmarks

Then the same + trick as iMessage's stacked tapbacks counts them: .tb-check + .tb-check is the second, and each extra + .tb-check is one further along, so the second is green, the third lime, and so on round to violet for the twelfth. The blue line comes last, so it wins over the counting and keeps that checkmark blue wherever it is. That's how the colours always come out in the right order, without you having to say which is which.

#workskin .tb .handle::after { background-repeat: no-repeat; background-position: right center; background-size: auto 0.9em; }

This one is for checkmarks that come from a character profile. The checkmarks are a picture, and this line puts it at the right-hand end of the name, at just under the height of the text. The profile adds the picture itself and some padding after the name to make room for it.

#workskin .tb .tb-checks { margin-left: 0.25em; color: #52b5f9; font-size: 0.85em; }

This is the tb-checks span, for the checkmark pictures on a blog without a profile. The pictures themselves are in the Icons section at the end of the module, the same as the buttons, and if they're taken out, this line shows the typed checkmarks instead, in blue and a little smaller than the name.

In the Icons section, the span becomes the picture, at just under the height of the name. Each number of checkmarks has its own width, the same as the padding a profile uses, so the gap after the name comes out the same either way.

15.3.3 Background

15.3.3.1 The Feed
#workskin .tb-feed {
  width: 380px;
  max-width: 100%;
  margin: 1.2em auto;
  padding: 0.5em 0;
  background: #001935;
  box-sizing: border-box;
  border-radius: 14px;
}

#workskin .tb-feed.black { background: #000000; }

#workskin .tb-feed.classic { background: #435874; }

/* the feed follows the theme too: theme-dark is always black, and theme-auto turns black in dark mode */
#workskin .tb-feed.theme-dark { background: #000000; }

@media (prefers-color-scheme: dark) {
  #workskin .tb-feed.theme-auto { background: #000000; }
}

#workskin .tb-feed .mob {
  width: auto;
  max-width: none;
  margin: 0.5em 0;
  border-color: transparent;
  border-radius: 14px;
}

The feed is a phone-sized navy box, Tumblr's own colour.

Options: changing the feed colour

Changing the feed colour: the colour is the background line in #workskin .tb-feed (#001935). Swap it for any colour you like, and every feed without black, classic or a dark theme changes with it. There's a note at that line in the CSS too.

How it works: the posts inside the feed, and its themes

The posts inside it lose their own width and fill the feed instead, with a small gap between each one and no visible edge, so they look like cards laid on the background. black swaps the navy for black, and classic for the old Tumblr blue. The feed also takes the same themes as the posts: theme-dark makes it black, and theme-auto keeps it navy until the reader's device is in dark mode, then turns it black, the same as Tumblr's own dark mode. It's the same @media trick the posts use for theme-auto. Give the feed the same theme as the posts inside it so they match.

15.3.3.2 The App Screen
#workskin .tb-feed.app { padding: 0; overflow: hidden; }

#workskin .tb-feed .tb-screen {
  display: block;
  max-height: 640px;
  overflow-y: auto;
  overflow-x: hidden;
  padding: 0 0 0.5em 0;
}

#workskin .tb-feed.no-scroll .tb-screen { max-height: none; overflow-y: visible; }

#workskin .tb-screen .tb { max-height: none; overflow: visible; }

With app, the feed itself doesn't scroll - the tb-screen inside it does, up to 640px tall.

How it works: what scrolls and what stays put

The buttons along the bottom come after the screen, outside it, so they stay where they are while everything in the screen scrolls past, and the top bar is inside the screen, so it scrolls away. The posts inside the screen lose their own scrolling, so there's only one scroll bar. Adding no-scroll to the tb-feed switches the screen's scrolling off too.

How it works: the top bar, the tabs and the bottom buttons

The top bar, the tabs and the bottom buttons are flex rows like the bottom of a post. They have no background of their own, so they're always the feed colour, which is why the feed's black and classic work on them too. The picked tab is white with a short blue line under it, made with ::after the same way as the reblog badge, and the other tabs and buttons are grey. The Tumblr logo is just a bold "t". The icons are pictures, in the Icons section with the rest, and they're the same in every theme because they always sit on the feed.

15.3.4 Footer

15.3.4.1 Tags and the Bottom Row
#workskin .tb .tb-stats {
  display: flex;
  align-items: center;
  padding: 0.6em 0.9em 0.9em 0.9em;
  color: #555555;
}

#workskin .tb .tb-stat {
  display: block;
  flex: 1 1 0;
  white-space: nowrap;
}

#workskin .tb .tb-icon {
  display: inline-block;
  margin-right: 0.3em;
  font-size: 1.3em;
  line-height: 1;
  vertical-align: -0.15em;
}

#workskin .tb .tb-stats > .tb-icon { margin-right: 0; }

display: flex lines the bottom row up.

How it works: sharing out the width

Each tb-stat has flex: 1 1 0, which means "start from nothing and take an equal share of the spare room", so replies, reblogs and likes get a third each, however long their numbers are. The share button has no flex, so it only takes the room it needs, and that leaves it at the right-hand end. white-space: nowrap keeps a button and its count on the same line. The buttons are a little bigger than the counts, with a small gap before the number, and the share button doesn't need the gap because nothing comes after it.

An ask is a grey box with a little pointer on its right, aimed at the asker's picture, which sits outside the box.

How it works: the box, the pointer and the picture
  • The ask box is grey with a 50px margin on its right, leaving room for the picture outside it and a gap between the picture and the edge of the post.
  • The pointer is a CSS triangle - the same border trick as WhatsApp's bubble tails - pinned to the right edge, pointing at the picture.
  • The picture is pinned outside the box with right: -36px. It's a circle like the header picture, and it has its own colour1 to colour10.

The quote is big and in a serif font, and the curly quotation marks are added before and after it - \201C is “ and \201D is ”. The chat post is in a typewriter font.

  background-repeat: no-repeat;

  font-weight: bold;
  line-height: 1.3;
}

#workskin .tb .tb-text .tb-opt.results {
  justify-content: flex-start;
  border-color: transparent;
  border-radius: 8px;
  color: inherit;
  background-color: #f0f0f0;
  background-image: linear-gradient(#dcdcdc, #dcdcdc);
}

#workskin .tb .tb-text .tb-opt.results.win { background-image: linear-gradient(#a6d9ec, #a6d9ec); }

#workskin .tb .tb-opt .tb-pct { margin-left: auto; padding-left: 0.8em; font-weight: normal; white-space: nowrap; }

#workskin .tb .tb-opt.p50 { background-size: 50% 100%; }

This is built on the Twitter poll (see Polls). Before anyone's voted, each option is a blue outline with round ends and the text in the middle.

How it works: the results bars

With results it turns into a grey box with the text on the left, and a darker bar is drawn across it as a background: linear-gradient with the same colour twice is just a block of colour, and background-size sets how wide it is, so p50 fills half the box. win swaps the grey bar for blue. There's one line like that for each bar size. The box is a flex row, so margin-left: auto pushes the percentage to the right-hand end.

The .tb-text in the first two rules is there so they win over the body's own paragraph spacing. tb-pollinfo is the small grey centred line underneath. In dark posts the box, the bar and the line are darker.

15.4.5 Tappable Polls

#workskin .tb .tb-vote[open] > summary { display: none; }

#workskin .tb .tb-pick[open] > summary { visibility: hidden; }

#workskin .tb .tb-results { display: block; position: absolute; top: 0; left: 0; right: 0; z-index: 1; background: #ffffff; }

A <details> box opens when it's tapped, the same trick as Instagram's like and save buttons (see Clickable Buttons).

How it works: hiding the open poll, and the reader-picks version

In tb-vote, the open poll is the <summary>, and once it's tapped it's hidden, so only the results show. In the reader-picks version, each option is its own <details>, and its results are lifted out with position: absolute to sit over the whole tb-poll box, with the card's colour behind them so the blank boxes don't show through. The other lines hide the little triangle a <summary> normally has, and tb-voted is the small picture, pushed to the right next to the percentage.

15.5 Pictures and Gifs

#workskin .tb .tb-text .tb-row {
  display: flex;
  margin: 0 0 4px 0;
  padding: 0;
}

#workskin .tb .tb-photo {
  display: block;
  position: relative;
  flex: 1 1 0;
  overflow: hidden;
  background: #e8e8e8;
}

#workskin .tb .tb-photo img {
  display: block;
  width: 100%;
  max-width: none;
  height: auto;
  margin: 0;
  border-radius: 0;
}

Pictures go in rows, edge to edge across the card.

How it works: the rows

Each row is a flex row with a 4px gap under it, and each picture in it takes an equal share of the width (the same flex: 1 1 0 as the bottom row). The row is a paragraph so that AO3 doesn't add one of its own, which is why it needs padding: 0 to undo the body's paragraph padding. The picture fills its box, with the rounded corners and the gap round it that ordinary pictures in a post get taken off, so it goes edge to edge.

#workskin .tb .tb-row.two .tb-photo {
  height: 0;
  padding: 50% 0 0 0;
}

#workskin .tb .tb-row.two .tb-photo img {
  position: absolute;
  top: -9999px;
  bottom: -9999px;
  left: 0;
  margin: auto 0;
}

Two side by side are squares.

How it works: making a square and cropping the picture

A box with no height and padding-top: 50% is as tall as half the row is wide, so it's square, whatever is inside it. The picture is pinned in the middle of the box and anything sticking out of the top and bottom is hidden, the same cropping trick as the Twitter/X photos (see Pictures and Videos). landscape swaps it round for a wide picture, so it's as tall as the box and the sides get cropped instead. The grey background only shows while a picture is loading.

#workskin .tb .tb-text > .tb-photos:first-child,
#workskin .tb .tb-reblog > .tb-blog + .tb-photos { margin-top: -0.3em; }

#workskin .tb .tb-link { color: #3a5f86; }

Pictures at the very start of a post, or straight after a reblog's header, get a small negative margin to cancel out the gap at the top of the body, so they sit right up against the header.

How it works: directly inside, straight after, and mentions

> means "directly inside", and + means "straight after". The tb-link mentions are a dusty blue, just different enough from the text to stand out (the dark theme makes them a pale blue instead).

How it works: the rounded corners

15% rounds the corners by the same amount whatever the size of the square. A profile does the same thing with its own border-radius line (see Round or Square Pictures).

15.7 Links

#workskin .tb .fake-link, #workskin .tb a:not(.tl) { color: #0070b8; }

Links are Tumblr's blue.

15.8 Dark and Auto Themes

The dark theme makes the card dark grey (#1f1f1f) with light text, turns all the small print and the ask boxes darker, and gives links a brighter blue (#00b8ff) so they show up. The white edges round the reblog badge become the card colour. As always, the auto theme is the same again inside @media (prefers-color-scheme: dark).

15.9 Taking Parts Out

Search for the class names and delete every rule with them in, including in the dark and auto blocks:

  • Asks: tb-ask, tb-asker and tb-ask-pfp.
  • Quote posts: tb-quote and tb-source.
  • Chat posts: tb-chat.
  • Polls: tb-opt, tb-pct, tb-pollinfo, tb-vote, tb-pick, tb-poll, tb-results and tb-voted.
  • Pictures and gifs: tb-photos, tb-row and tb-photo.
  • Mentions: tb-link.
  • Checkmarks: tb-check, tb-checks and the ic-checks lines in the Icons section.
  • Bottom row: tb-stats, tb-stat and tb-icon.
  • The feed: everything starting .tb-feed.
  • Just the app screen: the rules with .tb-feed.app, tb-screen, tb-header, tb-logo, tb-topicon, tb-tabs, tb-tab, tb-nav and ic-tb- in them.

Keep the card, the header, the name, the picture and the body, which every post uses.
