This chapter goes through the CSS for the WhatsApp chats in the last chapter. WhatsApp is a much bigger module than iMessage - it has headers, galleries, link cards and wallpapers - but it's built the same way, so if you've read the iMessage CSS chapter, a lot of this will look familiar. Where something works exactly like it does in iMessage, I'll point you back there rather than explain it twice.

Each part starts with the CSS itself and a line or two on what it does. The Options boxes show what you can safely change, and the How it works boxes go through the rules a line at a time, if you want to learn how it's put together.

7.1 Getting the CSS

The WhatsApp CSS is here: jockles.com/fic/megaskin/css/whatsapp.css. It needs the core CSS too, so paste the core into your work skin first and this underneath it.

7.2 How the Module is Laid Out

It's in the same order as every module - the main rules, then Links, Dark theme and Auto theme - with one extra section on the end: Wallpapers. They come last on purpose. When two rules are equally specific, the one further down wins, so a wallpaper beats the background that the dark and auto themes set. That's how a chat can be theme-auto and still keep its blush pink wallpaper in dark mode. After the wallpapers come the Icons, which don't touch the background, so they can sit after them.

7.3 The Container

7.3.1 The Window

#workskin .wa {
  background-color: #efeae2;
  background-image: url(https://images.squidge.org/images/2026/11/18/whatsapp-bck-light.jpg);
  background-size: 100% auto;
  background-repeat: repeat-y;
  color: #111b21;
  border: 1px solid #d1d7db;
  border-radius: 10px;
}

The background is WhatsApp's own doodle wallpaper, one phone-screen-sized picture. The beige background-color shows if the picture doesn't load.

How it works: making one picture fit any chat

background-size: 100% auto stretches it to the width of the chat and keeps its shape, and repeat-y repeats it down the page when a chat is longer than one screen.

7.3.2 Header

#workskin .wa .mob-header {
  background: #008069;
  color: #ffffff;
  text-align: left;
  padding: 0.7em 1em;
}

This is the plain header, with only a name in it. #008069 is WhatsApp's green.

The header with the back arrow, picture and icons is a table, because tables are one of the few layouts AO3 never rearranges. (It's the approach from the WhatsApp group chat skin in the credits.)

#workskin .wa table.wa-header {
  width: 100%;
  table-layout: fixed;
  border-collapse: collapse;
  border-spacing: 0;
  margin: 0;
  background: #008069;
  color: #ffffff;
  text-align: left;
}

#workskin .wa table.wa-header td {
  margin: 0;
  padding: 0;
  border: 0;
  background: transparent;
  color: inherit;
  font: inherit;
  vertical-align: middle;
}
How it works: the header table
  • AO3, and some site skins, give tables borders, stripes and padding. The second rule wipes all of that off every cell.
  • table-layout: fixed makes the columns keep the widths they're given, instead of stretching to fit whatever's in them. Without it, a long group name would squash the icons.
#workskin .wa table.wa-header .wa-name {
  padding: 0.55em 0.4em 0 0.4em;
  font-weight: bold;
  line-height: 1.2;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

A long name gets cut off with "..." like on a phone.

How it works: cutting off a long name

These three lines are how a long name gets cut off with "..." like on a phone: nowrap keeps it on one line, overflow: hidden hides what doesn't fit, and text-overflow: ellipsis adds the dots.

The member list (wa-status) does the same. The back arrow, picture and icons cells have set widths in pixels, and the title takes whatever room is left.

7.3.3 Wallpapers

#workskin div.mob.wa.bg-sage { background: #d5e6d0; }

#workskin div.mob.wa.bg-sunset { background-color: #f6a56d; background-image: linear-gradient(#f6d365, #fda085); }

Each wallpaper is one line. A plain one is a colour. A gradient fades from the first colour at the top to the second at the bottom, and also has a plain background-color in between the two, which shows in the rare reader that can't do gradients. To make your own, copy a line, give it a new name after bg-, and change the colours.

Options: using your own picture

Using your own picture takes one rule, which is already in the skin waiting for you:

#workskin div.mob.wa.bg-image1 {
  background-color: #1c1c1c;
  background-image: url(https://example.com/my-wallpaper.jpg);
  background-size: cover;
  background-position: center;
}
  1. Upload your picture somewhere that gives you a direct link to it - one that ends in .jpg or .png. (See Pictures and Alt Text for where.)
  2. Put your link in place of https://example.com/my-wallpaper.jpg, keeping the brackets.
  3. Change #1c1c1c to a colour close to your picture. It shows while the picture loads, or if the link ever breaks.
  4. Use it like any other wallpaper: <div class="mob wa theme-auto bg-image1">

background-size: cover stretches the picture to fill the chat without squashing it, cropping whatever doesn't fit, and center keeps the middle of it in view. For a second picture, copy the whole rule and call it bg-image2.

Options: picking a theme to go with a wallpaper

A wallpaper changes the background, but not the bubbles. A dark wallpaper with light bubbles, or a pale one with dark bubbles, can look odd, so match them up: theme-light with the pale wallpapers, theme-dark with slate, navy, forest, plum, black, night and dusk. theme-auto works with anything in the middle.

How it works: why every wallpaper starts with div.mob

The div.mob at the start makes a wallpaper stronger than a phone owner's wallpaper, so pov-shane bg-sage shows sage even on Shane's phone. Keep it when you copy a line.

How it works: a one-off wallpaper in the HTML

A one-off wallpaper in the HTML uses these rules instead:

#workskin .mob.wa { position: relative; }

#workskin .wa .wa-wall {
  position: absolute;
  top: 0;
  right: 0;
  bottom: 0;
  left: 0;
  margin: 0;
  overflow: hidden;
}

#workskin .wa .wa-wall img {
  position: absolute;
  top: -9999px;
  right: -9999px;
  bottom: -9999px;
  left: -9999px;
  margin: auto;
  min-width: 100%;
  min-height: 100%;
  max-width: none;
  max-height: none;
}

#workskin .wa .mob-header,
#workskin .wa .wa-header,
#workskin .wa .mob-body,
#workskin .wa .wa-footer { position: relative; }

The wa-wall box is pinned to all four edges of the chat with position: absolute, and overflow: hidden crops anything that sticks out. The picture inside is told to be at least as wide and as tall as the chat, keeping its shape, and the huge minus numbers with margin: auto centre it. The last rule gives the header, messages and message bar a position too, which lifts them on top of the picture.

7.3.4 Footer

7.3.4.1 The Message Bar
#workskin .wa .wa-footer { position: relative; padding: 0.5em 3.4em 0.5em 0.6em; }

#workskin .wa .wa-footer br { display: none; }

#workskin .wa .wa-field {
  display: table;
  width: 100%;
  box-sizing: border-box;
  padding: 0.45em 0.8em;
  border-radius: 2em;
  background: #ffffff;
  color: #667781;
}

#workskin .wa .wa-field span {
  display: table-cell;
  vertical-align: middle;
  white-space: nowrap;
  width: 1%;
  padding-left: 0.5em;
}

#workskin .wa .wa-field .wa-placeholder { width: auto; padding-left: 0.5em; }

#workskin .wa .wa-mic {
  position: absolute;
  right: 0.6em;
  top: 50%;
  margin-top: -1.2em;
  width: 2.4em;
  height: 2.4em;
  line-height: 2.4em;
  text-align: center;
  border-radius: 50%;
  background: #00a884;
  color: #ffffff;
}

The message bar is a white box with its icons inside it, and the round green microphone beside it.

How it works: the box, the icons and the microphone
  • br { display: none; } is there because AO3 turns line breaks in your HTML into <br /> tags, and inside the bar they'd split it onto two lines. This rule just ignores them.
  • The white box is another table, and each icon is a cell. width: 1% on the icons is a trick: a table cell can't be narrower than what's inside it, so asking for 1% makes it exactly as wide as its icon. The placeholder (wa-placeholder) is set back to auto, so it takes all the room that's left.
  • The green microphone circle is pinned in the space on the right, which the bar's 3.4em of right padding keeps clear. It's centred top to bottom with top: 50% and a negative margin of half its height.
How it works: a half-typed message

For a half-typed message, typed undoes the nowrap so long messages wrap, and makes the words dark (light in dark mode):

#workskin .wa .wa-field .wa-placeholder.typed { white-space: normal; color: #111b21; }

#workskin .wa .wa-field .cursor { display: inline-block; width: 0.2em; padding: 0; }

Every span in the bar is a table cell, which would make a flashing cursor (from the core) a cell of its own and stretch the bar. The second rule keeps it a thin box in the line of words.

7.3.4.2 Typing Dots
#workskin .wa .msg.typing-indicator { min-width: 0; padding-top: 0.7em; padding-bottom: 0.55em; line-height: 1; }

#workskin .wa .typing-indicator span:empty { background: #8696a0; }

The dots go inside an ordinary message bubble, so they get everything a message gets: the colour, the tail, and in a group, the picture. The dots themselves are in the core CSS, the same for every chat app (see Typing Dots). min-width: 0 undoes the usual minimum width, which is there to fit the time, so the bubble shrinks to fit the dots, and the second rule gives them WhatsApp's grey.

7.4 Normal Messages

7.4.1 Bubbles

#workskin .wa .msg {
  display: table;
  max-width: 80%;
  min-width: 90px;
  margin: 0.2em 0;
  padding: 0.35em 0.6em 0.3em 0.6em;
  border-radius: 8px;
  box-shadow: 0 1px 1px rgba(0, 0, 0, 0.13);
}

#workskin .wa .out { margin-left: auto; background: #d9fdd3; }

#workskin .wa .in { margin-right: auto; background: #ffffff; }

The bubbles work like iMessage's: display: table makes them fit their words, and auto margins push them to one side.

How it works: what's different from iMessage

The differences are:

  • min-width: 90px, so even a one-word bubble is wide enough for the time and ticks underneath.
  • Smaller rounded corners (8px), because WhatsApp's bubbles are squarer.
  • box-shadow, which is the faint shadow under each bubble: 0 across, 1px down, 1px blurry, in black at 13% strength.

7.4.2 Bubble Tails

#workskin .wa .msg.tail { position: relative; }

#workskin .wa .in.tail { border-top-left-radius: 0; }

#workskin .wa .in.tail::before {
  content: '';
  position: absolute;
  top: 0;
  left: -8px;
  width: 0;
  height: 0;
  border-style: solid;
  border-width: 0 8px 10px 0;
  border-color: transparent #ffffff transparent transparent;
}

The tail is the little point on the top corner of a bubble. Sent bubbles have the same thing mirrored, in green.

Options: changing a bubble colour

If you change a bubble colour, change its tail too, or you'll get a white point on a coloured bubble.

How it works: drawing a triangle with borders

The tail is a triangle, and CSS draws triangles in a strange way. A box with no width and no height, but with thick borders, is just its borders - and where two borders meet, they meet at a slant. Make three of the borders see-through, and the one that's left is a triangle. Here, only the right-hand border has a colour (the second of the four in border-color, which go top, right, bottom, left), so the triangle points left. It's pinned just outside the top corner, which has its rounding taken off so the two join up.

Its big padding makes room for the fade, a radial-gradient that's dark in the very corner and fades to see-through, so the white time shows up on any picture. With a caption in between, the rule doesn't match, and the time goes back under the caption. The last three rules swap the ticks for white ones, and the read ticks use the white pair too, since WhatsApp doesn't turn them blue on a photo.

7.6.2 Photo Galleries

Galleries are the trickiest part of the skin, because every photo has to be a perfect square, whatever shape the picture is. Every chat app builds its photos this way, so these rules live in Core, under Chat Photos, and each one lists the same class for every app (imsg-photo, wa-photo, igdm-photo, twdm-photo, dc-photo). Only the WhatsApp line is shown here.

#workskin .wa-photo {
  display: block;
  position: relative;
  float: left;
  width: 49%;
  height: 0;
  padding: 49% 0 0 0;
  margin: 0 1% 1% 0;
  overflow: hidden;
  background: rgba(0, 0, 0, 0.12);
}
How it works: the squares and the grid
  • The square: CSS has no simple way to say "as tall as it is wide" that works everywhere, but padding given in % is always a percentage of the width, even top padding. So height: 0 with padding-top: 49% makes a box exactly as tall as its 49% width. A tall photo uses 99%, which is two squares and the gap between them.
  • The grid: float: left lines the photos up two to a row. Two photos and the 1% gap make 99%, not 100%, so that rounding in the browser can never make a row a hair too wide and push a photo down to the next line.
  • nth-of-type rules take the gap off the right of every second photo, and off the bottom of the last row. The br rule hides AO3's line breaks here too, because in a grid they'd push photos out of place.
#workskin .wa-photo img {
  position: absolute;
  top: -9999px;
  bottom: -9999px;
  left: 0;
  display: block;
  width: 100%;
  height: auto;
  min-width: 0;
  min-height: 0;
  max-width: none;
  max-height: none;
  margin: auto 0;
}

#workskin .wa-photo img.landscape,
#workskin .wa-photos.two .wa-photo img,
#workskin .wa-photos.three .wa-photo:first-of-type img {
  top: 0;
  bottom: auto;
  right: -9999px;
  left: -9999px;
  width: auto;
  height: 100%;
  margin: 0 auto;
}

Each picture is centred in its box, so whatever doesn't fit is cropped evenly.

How it works: centring a picture in its box

This is the same centring trick as round pictures in the core, but from top to bottom: the picture is made as wide as the square and given an enormous space above and below, and margin: auto puts it in the middle, so the extra top and bottom are cropped evenly. landscape turns it on its side. The tall boxes always use the landscape way, because almost every photo is wider than a box two squares tall.

How it works: two, three and one photos 
#workskin .wa-photos.two .wa-photo {
  padding-top: 99%;
  margin-bottom: 0;
}

#workskin .wa-photos.three .wa-photo:first-of-type {
  padding-top: 99%;
  margin-bottom: 0;
}

#workskin .wa-photos.one .wa-photo {
  float: none;
  width: 100%;
  height: auto;
  max-height: 26em;
  padding: 0;
  margin: 0;
}
  • two makes both photos tall, side by side.
  • three makes the first one tall, and the other two float into the space beside it, one on top of the other.
  • one undoes the square entirely - no float, no padding trick - so the picture keeps its own shape. max-height: 26em trims a very tall one at the bottom.

The card's picture is cut off at 190px tall, so a tall preview doesn't take over the chat. A video (video) is always 190px tall instead, and a description (text) gets padding to make it about that size.

How it works: the link symbol

\1F517 is the code for the 🔗 emoji, added before the address with ::before, so you don't have to type it.

A circle with no picture shows initials. A picture or a profile goes inside with a pfp span, which the core crops into the circle. The circle in the header is the same, just bigger (38px).

Options: the ten colours

Add colour1 to colour10 to a circle for its colour, and the same number to a name (who) or a quoted reply (wa-quote) to colour the name and the line down the side. The ten colours are in the core, shared with every app - see The Ten Colours for how to change them.

How it works: initials in the middle of the circle

The initials are centred the same way as in every app's circle: display: flex, with align-items centring them top to bottom and justify-content side to side.

7.7.2 Group Messages With Pictures

#workskin .wa .wa-row { position: relative; padding-left: 38px; margin: 0.2em 0; }

#workskin .wa .wa-row .wa-pfp { position: absolute; left: 0; top: 0; }

#workskin .wa .wa-row .msg { margin: 0; }

#workskin .wa .wa-row.same { padding-left: 38px; }

A wa-row leaves a 38px gap down its left side, and the picture is pinned into that gap at the top. same keeps the gap but has no picture in it, so later messages from the same person still line up.

#workskin .wa .wa-no {
  float: right;
  margin-left: 1em;
  font-weight: normal;
  color: #667781;
}

float: right sends the phone number to the far right of the name line, and the name stays on the left.

7.8 Dark and Auto Themes

The dark theme swaps the wallpaper for WhatsApp's dark version (with its near-black underneath), the bubbles for dark grey and dark green, and every bit of grey text for a lighter grey. It also has the lighter set of name colours, and the tails again in the new bubble colours. As in iMessage, the auto theme is the same rules again inside @media (prefers-color-scheme: dark), so change a dark colour in both places.

#workskin .wa.theme-dark { background-color: #0b141a; background-image: url(https://images.squidge.org/images/2026/11/18/whatsapp-bck-dark.png); color: #e9edef; border-color: #222d34; }

#workskin .wa.theme-dark .out { background: #005c4b; color: #e9edef; }

#workskin .wa.theme-dark .in { background: #202c33; color: #e9edef; }

#workskin .wa.theme-dark .in.tail::before { border-color: transparent #202c33 transparent transparent; }

#workskin .wa.theme-dark .out.tail::before { border-color: transparent transparent transparent #005c4b; }

7.9 Taking Parts Out

WhatsApp is a long module, so it's worth trimming if you only use a few parts. These come out cleanly - search for the class names and delete every rule with them in, including in the dark and auto blocks:

  • Header with a picture and icons: wa-header, wa-back, wa-name, wa-status, wa-btns. Keep wa-pfp if you use pictures beside messages.
  • Pictures beside messages: wa-row and indent, and wa-pfp with its colours if you don't use the group header either.
  • Reactions: wa-reacts and wa-count.
  • Message bar: wa-footer, wa-field, wa-placeholder, wa-mic.
  • Link cards: share, and everything starting wa-link.
  • Photos: gallery, wa-photos, wa-photo, img-desc.
  • Calls: call, and everything starting wa-call, including the ic-wa-call and ic-wa-video icons.
  • Contact cards: contact, wa-contact and wa-contact-btn.
  • Forwarded label: wa-fwd and ic-forward.
  • Wallpapers: any bg- line you don't use.

Leave the window, bubbles, time and theme blocks, which everything else depends on.
