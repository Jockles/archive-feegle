Chapter 11: Classic Twitter CSS

This chapter goes through the CSS for the two classic Twitter modules in the last chapter. They're completely separate, so each has its own section and its own CSS, and you only need the one for your fic's years.

11.1 The 2012-15 CSS

11.1.1 Getting the 2012-15 CSS

The 2012-15 CSS is here: jockles.com/fic/megaskin/css/twitter-classic-2012.css. It needs the core CSS too, so paste the core into your work skin first and this underneath it.

11.1.2 How the 2012-15 Module is Laid Out

The tweet comes first, then an opened tweet, then the app screen with its two bars, and Icons at the end. There's no Dark or Auto section, because Twitter had no night mode yet. Every rule starts with .twc12 or .twc12-feed, so even though the parts inside have the same names as other Twitter modules (tw-top, tw-stats and so on), nothing gets in anything else's way.

11.1.3 The 2012-15 Bars

#workskin .twc12-feed .twc-header {
  display: flex;
  position: sticky;
  top: 0;
  background-color: #3b94d9;
  background-image: linear-gradient(#6db9ef, #3b92d8 55%, #2f83c8);
  text-shadow: 0 -1px 0 rgba(0, 0, 0, 0.35);
}

#workskin .twc12-feed .twc-title {
  position: absolute;
  left: 4.5em;
  right: 4.5em;
  text-align: center;
}

#workskin .twc12-feed .twc-title + .ic { margin-left: auto; }

These are the two bars of the app screen: the blue one along the top, and the black row of buttons along the bottom. Both stay put while the tweets scroll between them.

How it works: the shine on the bars

The shine on the bars comes from linear-gradient, which fades from one colour to the next down the bar. Each colour can have a point to stop at, so the blue bar is lightest at the top and darkens past the middle, and the black bar along the bottom jumps from one shade to a darker one exactly halfway down, which gives it a glassy edge. background-color underneath is a plain colour for anything that can't show the gradient, and the dark text-shadow one pixel above the page name makes it look pressed into the bar. The icons have their shine and shadow drawn into the pictures themselves.

How it works: keeping the bars in place, and the page name in the middle

position: sticky keeps the bar at the top of the screen while the tweets scroll under it, and the black row of buttons does the same at the bottom with bottom: 0. The page name is taken out of the row and stretched across the middle, so it stays centred whether there's one button on the left and two on the right or anything else, and margin-left: auto pushes the buttons after it over to the right. Each tw-tab in the bottom row has its icon as a block, so the name drops underneath it.

The screen scrolls once it's taller than a phone, and no-scroll on the twc12-feed switches that off:

#workskin .twc12-feed.no-scroll { max-height: none; overflow-y: visible; }

11.1.4 The 2012-15 Picture Column

#workskin .twc12 {
  position: relative;
  padding: 0.65em 0.8em 0.6em 4.6em;
}

#workskin .twc12 .tw-pfp {
  position: absolute;
  top: 0.75em;
  left: 0.8em;
  width: 48px;
  height: 48px;
  border-radius: 5px;
}

#workskin .twc12 .tw-time {
  position: absolute;
  top: 0.75em;
  right: 0.8em;
}

The big left padding on the tweet leaves an empty column down the side, and the picture is pulled out of the line with position: absolute and pinned into it. The time is pinned into the top right corner the same way, and the name line has some padding on the right so a long name never runs underneath it.

Options: rounder or squarer pictures

The border-radius of 5px is what makes the pictures squares with soft corners. Make it bigger for rounder corners, or 0 for sharp ones.

How it works: an opened tweet

An opened tweet (big) takes the left padding away again and gives the name line its own padding instead, so the picture sits beside the name and the words run the whole width underneath.

11.1.5 Taking Parts Out of 2012-15

  • The app screen: everything starting .twc12-feed.
  • Opened tweets: the rules with .big, tw-date, tw-counts and twc-reply-bar.
  • Details: the tw-details rule.

11.2 The 2016-19 CSS

11.2.1 Getting the 2016-19 CSS

The 2016-19 CSS is here: jockles.com/fic/megaskin/css/twitter-classic-2016.css. It needs the core CSS too, so paste the core into your work skin first and this underneath it.

11.2.2 How the 2016-19 Module is Laid Out

The tweet comes first, then conversations, an opened tweet, the app screen with its two bars, the Dark and Auto themes, and Icons at the end. Every rule starts with .twc16 or .twc16-feed, so even though the parts inside have the same names as other Twitter modules (tw-top, tw-stats and so on), nothing gets in anything else's way.

11.2.3 The 2016-19 Bars

The bars work the same way as the 2012-15 ones: position: sticky keeps them at the top and bottom of the screen while the tweets scroll between them, and the page name is stretched across the middle of the top bar so it always stays centred.

How it works: the blue number on a button

The blue number on a button is the icon in a badged box, with the number pinned to its top right corner with position: absolute.

The screen scrolls once it's taller than a phone, and no-scroll on the twc16-feed switches that off:

#workskin .twc16-feed.no-scroll { max-height: none; overflow-y: visible; }

11.2.4 2016-19 Dark and Auto Themes

Night mode is #15202b for the background, white for the text, #8899a6 for grey and #38444d for the lines. The auto theme is the dark rules again inside @media (prefers-color-scheme: dark), so change a colour in both places.

11.2.5 The 2016-19 Picture Column

#workskin .twc16 {
  position: relative;
  padding: 0.65em 1em 0.5em 4.75em;
}

#workskin .twc16 .tw-pfp {
  position: absolute;
  top: 0.75em;
  left: 1em;
  width: 48px;
  height: 48px;
  border-radius: 50%;
}

The big left padding on the tweet leaves an empty column down the side, and the picture is pulled out of the line with position: absolute and pinned into it. Everything else in the tweet - the label, the name line, the words and the buttons - lines up in the space beside it, with no extra boxes needed. The little arrow is pinned into the top right corner the same way.

How it works: an opened tweet

An opened tweet (big) takes the left padding away again and gives the name line its own padding instead, so the picture sits beside the name and the words run the whole width underneath.

11.2.6 The Conversation Line

#workskin .twc16-feed .twc16.link::before,
#workskin .twc16-feed .twc16.link + .twc16::before {
  content: "";
  position: absolute;
  left: 1em;
  width: 2px;
  margin-left: 23px;
  background: #ccd6dd;
}

#workskin .twc16-feed .twc16.link::before { top: 0.75em; bottom: 0; margin-top: 52px; }

#workskin .twc16-feed .twc16.link + .twc16::before { top: 0; height: 0.7em; }

This is the grey line that joins a tweet to the reply underneath it.

How it works: one line in two pieces

The line is drawn in two pieces. The first runs from just under the linked tweet's picture to the bottom of that tweet, and the second, on the tweet underneath (the + means "the next tweet along"), runs from its top edge down to its picture. Together they look like one line. The 23px margin-left puts the 2px line in the middle of the 48px pictures.

11.2.7 Taking Parts Out of 2016-19

  • The app screen: everything starting .twc16-feed.
  • Opened tweets: the rules with .big, tw-date and tw-counts.
  • The little arrow: the rules with tw-menu and ic-dropdown.
  • Themes: the Dark and Auto sections, and the dark and auto parts of the Icons section.
