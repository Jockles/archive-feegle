This chapter goes through the CSS for the Discord chats in the last chapter: the window, the channel header, messages and their pictures, replies, reactions, spoilers, dividers, and the dark theme.

Each part starts with the CSS itself and a line or two on what it does. The Options boxes show what you can safely change, and the How it works boxes go through the rules a line at a time, if you want to learn how it's put together.

Getting the CSS

The Discord CSS is here: jockles.com/fic/megaskin/css/discord.css. It needs the core CSS too, so paste the core into your work skin first and this underneath it.

How the Module is Laid Out

The usual order - the main rules, Links, Dark theme and Auto theme - with one extra part at the end, for parts borrowed from the other chat apps. Discord is the odd one out in a few ways:

  • It's built from the same parts as the other chat apps (mob-header, row, avatar, who, msg, footer), but with no bubbles: the messages are plain text beside a round picture.
  • The little icons in the header and the message box are pictures hosted on squidge.org, not text.
  • It uses rem for most sizes, where the other modules use em. A rem is the size of the page's normal text, so the sizes stay the same wherever the chat sits.

The header is the same mob-header line as the other chat apps, made 56 pixels tall with a soft line under it, and kept on one line.

How it works: the soft line and the symbol
  • The line under the header is three thin shadows stacked up, which fade out like Discord's soft edge instead of a hard line.
  • The left padding of 3rem leaves room for the symbol, which is an empty box made with ::before.
  • Anything too long is cut off with "...".

#workskin .dc .at-symbol::before { background-image: url(https://images.squidge.org/images/2026/11/15/dc-at-light.png); }

The symbol before the channel name is a picture. Adding hashtag, locked or at-symbol to the header picks which picture: # for a channel, a padlock for a private channel, or @ for a DM. The dark theme swaps each one for a lighter version, so they show up on the dark background.

Each row is pushed in from the left, which leaves room for the round picture. The name and the messages are plain lines of text, with no bubbles. The name line is flex, so it looks the same whether its parts are written on one line or on several.

How it works: the row, and spaces in messages
  • min-height makes each row at least as tall as the picture, so short messages don't overlap the next one.
  • break-spaces keeps any extra spaces you type in a message, and break-word breaks up very long words (like a keysmash) so they don't run off the edge. It's only on one-line messages (p.msg), because on a message with a picture or link card in it, it would turn the line breaks in your code into big gaps.

Options: the ten colours

Adding colour1 to colour10 to the avatar colours the circle, and adding it to the who line colours the name. The colours are in the core, shared with every app, with brighter shades for names and lighter ones again in the dark theme - see The Ten Colours.

How it works: taking the picture out of the line

position: absolute takes the picture out of the row and puts it 1.25rem from the left edge, in the space the row's padding left free. It has no top, so it stays level with wherever the name line is - under a reply, if there is one.

  • Reactions are grey pills, but adding me to one makes it blue with a blue edge, like a reaction your POV character has added.
  • Adding me to a mention lights up that message line in yellow, with a line down its left side - what Discord does when someone @s you.
How it works: lighting up the whole message

This is :has() again: "a message that has a dc-mention me inside it". The minus margins stretch the yellow out to both edges of the window, and the padding puts the words back where they were.

Spoiler Text

#workskin .dc .dc-spoiler-text {
  border-radius: 0.1875rem;
  display: inline-block;
  cursor: pointer;
  color: rgb(185, 187, 190);
  background-color: rgb(185, 187, 190);
  transition: all 0s 2147483647s;
}

#workskin .dc .dc-spoiler-text:active {
  color: rgb(46, 51, 56);
  background-color: rgb(229, 229, 229);
  transition: all 0s;
}

The spoiler text starts the same colour as its background, so you can't read it. Clicking it turns the text dark and readable, and it stays that way.

How it works: the 68-year trick

This is one of the cleverest tricks in the megaskin, and it's BookKeep's. The spoiler text starts the same colour as its background, so you can't read it. :active means "while it's being clicked", and then the text turns dark and readable.

On its own, that would hide the text again as soon as you let go. But the first rule has transition: all 0s 2147483647s - "wait 2,147,483,647 seconds before changing back". That's about 68 years, so once it's revealed it stays revealed.

The :active rule has transition: all 0s, so the reveal happens instantly. That matters: if the reveal took even a tenth of a second, a quick click would let go halfway through, and the 68-year wait would freeze the spoiler half-revealed, so the reader would have to click again and again.

  flex: 1;
  border-top: thin solid rgba(79, 84, 92, 0.48);
}

The date dividers are the same mob-sys line as the other chat apps, with a thin line on each side of the date.

How it works: lines on both sides

display: flex puts the line's parts in a row: the ::before line, the date, then the ::after line. flex: 1 makes both lines stretch to fill the space that's left, so the date ends up in the middle.

Links

#workskin .dc a:not(.tl):hover { color: rgb(0, 104, 224); text-decoration: underline; }

Links are Discord's blue, and get underlined when you hover.

Dark and Auto Themes

The dark theme is Discord's classic dark grey (rgb(54, 57, 63)) with light text. Code blocks, embeds and reactions go a shade darker, links go brighter, the names get their lighter colours, and the header icons and the message box button swap to their light versions. The spoilers get their own dark colours, with the same 68-year trick. The auto theme is the same again inside @media (prefers-color-scheme: dark), and plain dc or theme-light is the light theme.

Parts From the Other Chat Apps

The last part of the module catches parts that only the other chat apps use, so a chat swapped to Discord still looks right. A message with no row around it shows its hidden name as the name line, and the header's picture, back arrow and buttons, and the message bar's icons, are hidden.

Taking Parts Out

Search for the class names and delete every rule with them in, including in the dark and auto blocks:

  • Header: mob-header, chat-name, hashtag, locked and at-symbol.
  • Message box: footer and plus.
  • Replies: reply and quote.
  • Pictures and emoji: photos, dc-emoji and dc-inline-emoji.
  • Reactions: dc-reaction and count.
  • Link cards: everything starting link-.
  • Quotes and code: dc-quote and dc-code.
  • Spoilers: dc-spoiler and dc-spoiler-text.
  • Mentions: dc-mention and dc-role-mention.
  • Dividers: mob-sys, dc-new and dc-new-tag.
  • Extras: dc-new-user, dc-bot, and the typing dots (dc-typing and typing-indicator).

Keep the window, row, avatar, who, msg and time, which every message uses.
