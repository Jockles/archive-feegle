Taking the Megaskin apart

Posted 28-11-2026

In the roadmap post I said the next job was a bit of a code tidy-up. A quick rename, make the class names a bit more consistent, done by the weekend. Alas.

It turned into me taking the whole Megaskin apart and putting it back together, and honestly I'm really pleased with what came out the other end. None of it is live yet. It's all going up in one go, so this is a sneak peek at what's coming and why.

Why bother?

The Megaskin started as a pile of separate skins. I built each app at a different time, borrowing from different people's skins, and every time I learned a new trick I did the next app a bit differently. So by the end, the same thing had four different names depending on which app you were in. Reactions were written one way in WhatsApp, another way in Instagram, and a third way in iMessage. Same with replies, typing dots, photos, the bar you type in… you get the idea.

That's fine if you're me and you wrote it. It's not fine if you've never touched code before and you're trying to work out why your Instagram post looks nothing like the tutorial. And that's who the Megaskin is for. I want someone with no coding experience at all to be able to open the code and actually read it.

Step one: names

Every class is now the app's name plus one plain word. tw-photo is a photo on Twitter. ig-photo is a photo on Instagram. No abbreviations I'd have to explain, no clever names that only made sense at 2am. Over a hundred classes got renamed.

If you've already posted a fic with the old Megaskin, don't panic. I've built a little converter that swaps the old names for the new ones, so give me a shout and I'll send it your way.

Step two: every box is built the same way

This was the big one. I sat down and wrote myself a rulebook for how every single module has to be built, and then went back and made every app follow it.

  • An app has a header, a body and a footer. The header is the bar along the top, the body holds all the messages or posts, and the footer is the bar along the bottom.
  • A message or a post has a top, a main bit and a bottom. And those go where the real app puts them. A sender's name sits on top. A timestamp sits at the bottom. iMessage tapbacks sit above the bubble, so they're top. WhatsApp reactions sit under it, so they're bottom.
  • One part per line, in order. Top, then main, then bottom, each on its own line, so you can read the code from top to bottom the same way you read the chat.

That last one made me nervous, because AO3 has opinions about line breaks and I was worried it would add random gaps everywhere. So I tested it: one Tumblr post with everything crammed on one line, and the same post split over several lines. On AO3 they look identical. Phew.

Instagram and Twitter don't have a footer, and that's on purpose. In the real apps, the bar along the bottom disappears as you scroll, and there's just no satisfying way to do that in an AO3 skin. The "Tweet your reply" bar is still there, but only under a tweet you've opened, as the bottom of that tweet.

Step three: same part, same word

Then I went through every app side by side and made a decision for every single mismatch. Something like thirty of them, in one morning. Very glamorous.

So now every chat app uses the same plain word for the same part, with no app name in front of it at all. The bar you type in is msgbar. The little row of emojis is reacts. The picture circle is avatar. A reply is reply. Describing a photo for readers who can't see it is img-desc everywhere, and video-desc for videos. Learn it once, use it in every app.

The bit I'm most excited about

Because the chats are all built from the same parts now, you can change one word on the top line and the whole chat turns into a different app. Write a conversation in iMessage, change imsg to wa, and it's a WhatsApp chat. Change it to igdm and it's an Instagram DM. Twitter DMs and Discord too.

The bubbles turned out to just be decoration. Discord doesn't have bubbles at all, only a picture, a name and lines of text, but underneath it's the same chat. So I rebuilt Discord from scratch to match the others, and while I was in there I made it phone-sized by default, like every other app. It used to be the only one that sprawled across the whole page.

It's not always a perfect copy. Discord shows "Shane is typing…" in a line under the message bar, while the other apps show the dots as a bubble at the end of the chat, so if you flip one to the other the typing line stays where you wrote it. But nothing breaks and everything still shows up, which is more than I expected when I started.

And it's not just chats. The feeds got the same treatment, so every tweet, Instagram post and Tumblr post is now just a post, and the likes, reposts, comments and so on all have the same names in every app. That means you can flip a tweet into an Instagram post or a Tumblr post exactly the same way, by changing the app on the top line. Not every app shows every number, but the names are the same everywhere.

Other things that snuck in

  • Email is two modules now. Gmail and the plain email window are separate, the same way Classic Twitter has its 2012 and 2016 looks, so you only paste in the one you need.
  • Verified ticks live in the profile. Set a character up as verified once and the tick follows them around Twitter and Instagram, like Tumblr's checkmarks already did. And it works per account, so their main account can be verified while their private one isn't. You can still add one by hand if you want.
  • Profile pictures that change. If a character changes their picture halfway through your fic, you can give them a second (and third) one without making a whole new profile.
  • The tutorial follows the same rules. Every chapter teaches things in the same order, and every feature is in the big example at the top of its chapter. When a section explains something, it takes apart that top example instead of making up a new one.
  • The Fic Builder matches. Its settings go in the same order as the skin: header, body, footer, then top, main and bottom for each message or post. It writes the new names, and it still reads the old ones.

What's next

All of this is going up on the site together, and then it's the big AO3 update, which is going to be a fun day of copying and pasting twenty-one chapters. Yay???

After that, it's back to the roadmap, and every new app from here on gets built to the same rulebook from day one.

As always, if something doesn't make sense, or you've found a bit I missed, come and yell at me on Tumblr.
