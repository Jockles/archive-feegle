12.1 Instagram posts and comments

An Instagram post is a stack of lines inside one container, from the account name at the top down to the time at the bottom. The module class is ig. Before we begin, here's the two kinds of post you can build: a full post with everything the workskin can do, and a simpler one. The full HTML is underneath each, which you can copy and modify yourself. The rest of this section takes the HTML apart so that you can modify all the individual parts to say exactly what you want.

12.1.3 Account Line

The first line is the account that posted. The name comes first, and the last <span> in the line adds the small grey line underneath it, which can be a song, like here, or a location. Straight after the name go the blue verified tick (ig-tick) and the "Follow" link (ig-follow). The three dots menu (ig-menu) sits at the far right, so it goes first in the line:

12.1.4 Profile Picture and Stories Ring

The profile picture goes at the very start of the account line, straight after the menu. It can show initials, an uploaded picture or a picture from a profile, and there's an example of each below.

For initials, type them inside a span with ig-pfp, and add one of colour1 to colour10 for a colour. With no colour class, the circle is grey:

SCscott.h

<p class="ig-top"><span class="ig-pfp colour3">SC</span>scott.h</p>

For an uploaded picture, put the picture tag inside a span with pfp, inside a span with ig-pfp. The pfp span crops the picture into a circle without squashing it, and the alt text should describe the picture (for example, "Profile picture of ilya.r"). If the picture is wider than it is tall, add class="land" to the picture tag (see Pictures in Boxes and Circles). To show that the account has a story up, add story to the ig-pfp span, which draws the colourful ring around the picture:

<span class="ig-pfp story"><span class="pfp"><img src="https://64.media.tumblr.com/2f5204e07f5dc3467a42508584f56c7d/188bbfab996df056-77/s400x600/e139f3e69f9be02470797bbd3505a69cc26def70.pnj" alt="Profile picture of ilya.r"></span></span>

Or use a profile, so the same person has the same picture everywhere, like Rose's in the simpler post. Put an empty pfp span with their profile name in the ig-pfp. The account name can come from the profile too, in a handle span with the name typed inside it in a hide span. That's for readers with the workskin switched off - the handle comes from the CSS, so without it they wouldn't know who posted (see Character Appearances and Profiles and Accessibility):

12.1.6 Buttons With Counts

The row of buttons is a div with ig-actions, and each button is its own paragraph with ig-btn. The symbol goes in a span with ig-icon, and the number in a span with ig-count. The comment bubble is drawn for you with ig-icon cm, and the others are plain symbols (a heart for likes, a circle arrow for repost, an arrow for share). After each number is a hide span with a word in it, like <span class="hide"> comments</span>, so readers with the workskin off get "2 comments" rather than a number on its own. Leave a button out if you don't want it on the post:

♡ 312 likes

2 comments

➤ 1 share

12.1.7 Clickable Like and Save Buttons

Readers can click or tap the heart and the save button to switch them on and off, like on the real app. Use them in place of the plain heart from the last section. The heart turns red and its count goes up by one, and the bookmark fills in:

♡ 2,431 likes (♥ 2,432 when liked)

84 comments

↻ 12 reposts

➤ 7 shares

Save

<details class="ig-tog like"><summary><span class="ig-icon off ic ic-heart">&#9825;</span><span class="hide"> </span><span class="ig-count off">2,431</span><span class="hide"> likes (</span><span class="ig-icon on ic ic-heart-red">&#9829;</span><span class="hide"> </span><span class="ig-count on">2,432</span><span class="hide"> when liked)</span></summary></details>

<p class="ig-btn"><span class="ig-icon ic ic-repost">&#8635;</span><span class="hide"> </span><span class="ig-count">12</span><span class="hide"> reposts</span></p>
<p class="ig-btn"><span class="ig-icon ic ic-share">&#10148;</span><span class="hide"> </span><span class="ig-count">7</span><span class="hide"> shares</span></p>
<details class="ig-tog save"><summary><span class="hide">Save</span><span class="ig-icon bm off"></span><span class="ig-icon bm on"></span></summary></details>
</div>
How the clickable buttons work

They're made with the details and summary tags. Inside the summary are two versions of the same thing: the parts with off show to begin with, and the parts with on swap in after a click. Click again, and it goes back. Because the number is in there too, you can make the likes go up by one. The save button (ig-tog save) sits on its own at the far right.

  • Keep each <details> on a single line of code, like above, and put them inside the ig-actions div, not inside a <p>.
  • To start with a button already switched on (a post the character has already liked, say), add open: <details class="ig-tog like" open>.
  • The clicking only works on AO3 itself, in a browser. In a download (EPUB, PDF and so on) the buttons stay as they started, so I'd recommend not having anything in your story depend on them being clicked.
  • If you don't want a clickable heart, use ig-btn for it instead, as in the last section. They look exactly the same until someone clicks.
  • The hide spans are for readers with the workskin off. Without them the heart reads "♡♥2,4312,432", and with them it reads "♡ 2,431 likes (♥ 2,432 when liked)". The save button gets a hidden "Save", because its bookmark is drawn by the workskin and disappears with it. You'll still see a small triangle in front of each one with the workskin off - that's the details tag's own marker, and only the workskin can hide it.

12.1.8 Liked By, With Faces

ig-likes is the likes line. Add liked-by to it for a "Liked by" line, which puts little overlapping profile pictures in front and keeps the text from being bold unless you put names in <b>. Each face is a span with ig-like-pfp, with the usual pfp and picture tag inside, all inside one ig-like-pfps span. Keep the faces together on one line, with no gaps between them. A picture that's wider than tall needs class="land" on its picture tag, like the second and third faces here, or it won't fill its circle (see Pictures in Boxes and Circles):

Liked by shane.h and others

12.1.9 Caption

ig-caption is the caption, with the poster's name in <b>. To colour a hashtag like Instagram does, wrap it in a span with ig-tag:

ilya.r early skate #nofilter

<p class="ig-caption"><b>ilya.r</b> early skate <span class="ig-tag">#nofilter</span></p>

To show a long caption cut short, like in a feed, stop partway through and end it with "... " and a grey ig-more span:

shane.h Here's where things stand at the quarter... more

<p class="ig-caption"><b>shane.h</b> Here's where things stand at the quarter... <span class="ig-more">more</span></p>

12.2.1 The Top Bar

The top bar is an ig-apptop line, with the + on the left, the logo in the middle and the heart on the right. The logo is a picture, and the word typed inside it is for readers with the workskin off. The little red dot on the heart means there's something new, so leave out the ig-dot span if there isn't:

+Instagram♡ (new)

<p class="ig-apptop"><span class="ig-new">+</span><span class="ig-logo">Instagram</span><span class="ig-notif ic ic-heart">&#9825;</span><span class="ig-dot"><span class="hide"> (new)</span></span></p>

12.2.2 The Stories Row

The Stories row is an ig-stories box, with one ig-story line for each circle: the picture in an ig-pfp, then the account name in an ig-sname span. Add as many as you like - the ones that don't fit are cut off at the edge, like in the app:

Your story

  • Long names end in "...", so you can type the whole name.

12.2.3 Posts in the Feed

Each post is a normal Instagram post, built the same way as in the first section, just without its own theme: the posts take their colours from the feed. Leave out the parts you don't need, like the "Liked by" faces or the comments, to keep the feed quick to scroll.

12.3.3 Instagram DM Window

Instagram DMs use the usual container, header and body, with the module class igdm, so the container is <div class="mob igdm theme-auto">. First comes the header:

shane.h - Active now

<p class="mob-head">shane.h<span class="hide"> - </span><span>Active now</span></p>

The span in the header is the status line, like "Active now" or "Active 2h ago". The name can be typed, like shane.h here, or it can come from a profile, in a handle span with the name typed inside it in a hide span:

shanehollanderhockeyplayer - Active now

<p class="mob-head"><span class="handle pfp-shane"><span class="hide">shanehollanderhockeyplayer</span></span><span class="hide"> - </span><span>Active now</span></p>

After the header comes <div class="mob-body">, which holds all of the messages.

12.3.4 Simple Messages

Messages are msg in and msg out paragraphs again. Messages you send are purple, and messages you get are grey:

Shane: you replied to my story

Ilya: I did not

<p class="msg in"><span class="hide"><em>Shane:</em> </span>you replied to my story</p>
<p class="msg out"><span class="hide"><em>Ilya:</em> </span>I did not</p>
Each part of a message, piece by piece
  • <p class="msg in"> - the bubble. in is grey on the left, out is purple on the right.
  • <span class="hide"><em>Shane:</em> </span> - only for readers with the workskin off. It's hidden in the chat, where the colours and sides show who's talking. With the workskin off, they don't, and a one-to-one DM has no names shown anywhere else, so this label is how those readers know who sent it.
  • you replied to my story - the message itself.

With the workskin off, this reads:

Shane: you replied to my story

Ilya: I did not

Swap the name for whoever is talking. There's more on this in Accessibility.

12.3.5 Shared Posts and Reels

When someone sends a post, a reel or a story into the chat, show it with igdm-shared, which makes an outlined box. It gets the hidden label too, so readers with the workskin off know who shared it:

Shane: Shared a story from @shane.h: "6am skate. Again."

<p class="igdm-shared"><span class="hide"><em>Shane:</em> </span>Shared a story from @shane.h: "6am skate. Again."</p>

12.3.6 Seen Status

The little "Seen" or "Sent" line under your last message is igdm-status, like the status line in iMessage:

Ilya: ok maybe I did

Seen

<p class="msg out"><span class="hide"><em>Ilya:</em> </span>ok maybe I did</p>
<p class="igdm-status">Seen</p>

12.3.7 Group Chats

For a group, put the group's name in the header. Above a message from someone else, put a who line to show who sent it. The name shows either way, so it only gets a hidden colon after it - your own messages, with no name above them, keep the full hidden label:

RoseLandry:

the lasagne is still here if anyone wants it

<p class="who">RoseLandry<span class="hide">:</span></p>
<p class="msg in">the lasagne is still here if anyone wants it</p>

For a character with a profile, put a handle span in the who line instead, with the name typed inside it in a hide span. DMs don't show profile pictures, so the name is all a profile adds here, but it keeps them the same as everywhere else:

RoseLandry:

and the garlic bread. I made too much

<p class="who"><span class="handle pfp-rose"><span class="hide">RoseLandry</span></span><span class="hide">:</span></p>
<p class="msg in">and the garlic bread. I made too much</p>
