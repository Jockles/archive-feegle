The Full Megaskin

This is the whole thing: the core and every module in one work skin. If you'd rather not pick and choose, this is the one to use.

Getting the CSS

The full megaskin is here: jockles.com/fic/megaskin/megaskin.css. It's the core plus every app, in the same order as this tutorial: iMessage, WhatsApp, Twitter/X, Instagram, Tumblr, Email and Discord.

Putting it on AO3

  1. Open the link above, select everything, and copy it.
  2. On AO3, go to Dashboard > Skins > Create Work Skin.
  3. Give it a title, paste everything into the CSS box, and submit.
  4. When you post or edit a fic, pick the skin under Associations > Select Work Skin.
  5. Use the HTML from the app chapters in your chapter text, in the HTML editor rather than the Rich Text one.
If AO3 won't save it

Check you copied the whole file - from the very first /* at the top to the very last */ at the bottom. A missing bracket anywhere can stop the rest from working.

If you'd rather keep the skin smaller, use the core and only the apps you need instead - the link is at the top of each CSS chapter.

What's in it

The top of the file has notes on how it's organised. The short version:

  • The core comes first, and every app needs it.
  • Each app runs from its >>>>>>>>>> MODULE line to its <<<<<<<<<< MODULE line, so you can delete any app you don't use by cutting everything between those two lines (and the lines themselves).
  • Every app is built the same way - main rules, Links, Scrolling, Dark theme, Auto theme - so once you know one, you can find your way round all of them.
