Before we begin, here's the two kinds of chat you can build: a message between two people, or a group chat. The full HTML is underneath each, which you can copy and modify yourself. The rest of the chapter takes the HTML apart so that you can modify all the individual parts to say exactly what you want.

A One-to-One Chat

Ilya:

Ilya: [A blurry photo of the same cat, now asleep on Ilya's hotel bed]

Read 11:52 PM

The iMessage Window

Every iMessage chat starts with the container, <div class="mob imsg theme-auto">, and everything else goes inside it. First comes the header, with the contact's name:

Ilya - iMessage

<p class="mob-head">Ilya<span class="hide"> - </span><span>iMessage</span></p>

mob-head is the header bar. The last <span> adds the smaller grey line under the name, like "iMessage" or "Mobile" - leave it out if you only want the name. After the header comes <div class="mob-body">, which holds all of the messages.

Simple Messages

Each message is a paragraph with the class msg, plus one more class that says who sent it. in is a message from the other person, which shows as a grey bubble on the left, and out is a message from your point-of-view character, which shows as a blue bubble on the right. Give every message its own <p>, one after another, inside mob-body:

Ilya: are you awake

Shane: no

<p class="msg in"><span class="hide"><em>Ilya:</em> </span>are you awake</p>
<p class="msg out"><span class="hide"><em>Shane:</em> </span>no</p>
Each part of a message, piece by piece
  • <p class="msg in"> - the bubble. msg makes it a bubble, and in or out says which side it sits on and what colour it is.
  • <span class="hide"><em>Ilya:</em> </span> - only for readers with the workskin off. In a one-to-one chat no names are shown anywhere, so this label is how those readers know who sent what.
  • are you awake - the message itself.

With the workskin off, this reads:

Ilya: are you awake

Shane: no

Date and Time Lines

For a centred line with the time or date, use mob-sys:

Today 11:48 PM

<p class="mob-sys">Today 11:48 PM</p>

It works for anything that isn't a message - a timestamp, "Yesterday", or a note partway through the chat, like when someone joins the group:

Ilya added Wyatt to the conversation

<p class="mob-sys">Ilya added Wyatt to the conversation</p>

Tapback Reactions

When someone reacts to a message, iMessage shows a tapback - a little bubble on the top corner of the message, with a tail of two dots. Add tapped to the message to make room above it, then put a span with imsg-tap at the end of the message text, with the emoji inside. imsg-tap on its own is grey, for someone else's reaction, and imsg-tap me is blue, for your point-of-view character's:

Ilya: liar [Shane reacted 😂]

Shane: ok yes. go to sleep, you have a game tomorrow [Ilya reacted 👎]

<p class="msg in tapped"><span class="hide"><em>Ilya:</em> </span>liar<span class="imsg-tap me"><span class="hide"> [Shane reacted </span>😂<span class="hide">]</span></span></p>
<p class="msg out tapped"><span class="hide"><em>Shane:</em> </span>ok yes. go to sleep, you have a game tomorrow<span class="imsg-tap"><span class="hide"> [Ilya reacted </span>👎<span class="hide">]</span></span></p>
More about tapbacks
  • Any emoji works, but each person can only react once, so it's one emoji per tapback.
  • It sits on the right-hand corner of a message from someone else, and the left-hand corner of your own, so you don't need to do anything to place it.
  • The two hide spans say who reacted, for readers with the workskin off: [Shane reacted goes before the emoji and ] goes after it. Copy them exactly, spaces included, so the bracket doesn't run into the message. With the workskin off, the second message reads Shane: ok yes. go to sleep, you have a game tomorrow [Ilya reacted 👎].

Pictures

To send a picture, add pic to a message and put a picture tag inside it. The corners are rounded for you. The picture has to be hosted somewhere else (see Pictures and Alt Text, in the Core, Themes, and Extras chapter), and your link goes in src, with your description in alt:

Ilya: 

<p class="msg in pic"><span class="hide"><em>Ilya:</em> </span><img src="https://64.media.tumblr.com/45b3b47d7c42b593f6242a40153a629c/ba033a52c8982cb0-d7/s2048x3072/4e71b117e87747d78dd3d95595cecc77eec48d38.jpg" alt="A cat curled up inside an open suitcase"></p>

If you'd rather describe the picture than show it, add text as well and write the description in square brackets:

Ilya: [A blurry photo of the same cat, now asleep on Ilya's hotel bed]

<p class="msg in pic text"><span class="hide"><em>Ilya:</em> </span>[A blurry photo of the same cat, now asleep on Ilya's hotel bed]</p>

Delivered and Read

iMessage shows a little status line under your last message. Add it with imsg-status, straight after the message it belongs to, and write "Delivered", "Read 11:52 PM" or whatever you like:

Shane: call me?

Read 11:52 PM

<p class="msg out"><span class="hide"><em>Shane:</em> </span>call me?</p>
<p class="imsg-status">Read 11:52 PM</p>

Typing Dots

For the three dots that show someone is typing, add a typing-indicator paragraph with three empty spans at the very end of the chat:

<p class="typing-indicator"><span></span><span></span><span></span></p>

Message Bar

To finish off the screen with the "iMessage" box along the bottom, add an imsg-input paragraph after the mob-body, still inside the chat. The + button is imsg-plus, the box is imsg-field, and the microphone is imsg-mic. The hide spans keep a space between them for readers with the workskin off, so it reads "+ iMessage 🎤" rather than running together. Keep it all on one line:

+ iMessage 🎤

<p class="imsg-input"><span class="imsg-plus">+</span><span class="hide"> </span><span class="imsg-field">iMessage<span class="hide"> </span><span class="imsg-mic">&#127908;</span></span></p>

Group Chats

In a group, put a who line above a message to show who sent it. Your own messages don't get one, the same as on a real phone, so they keep the hidden label instead. Change the header to the name of the group chat, and use the span for the members or "iMessage group":

Hayden:

day two of camp. who's awake

Scott:

unfortunately me

Shane: been up since 5. the cones are in my car

<p class="who">Hayden<span class="hide">:</span></p>
<p class="msg in">day two of camp. who's awake</p>
<p class="who">Scott<span class="hide">:</span></p>
<p class="msg in">unfortunately me</p>
<p class="msg out"><span class="hide"><em>Shane:</em> </span>been up since 5. the cones are in my car</p>

The who line shows whether the workskin is on or off, so it only needs a hidden colon after the name, to read "Hayden:" followed by the message.

Green Text Messages

When your point-of-view character's message goes as a normal text instead of an iMessage, it turns green - like Shane's, because the signal in the rink is too bad for iMessage. The same thing happens when they're messaging someone without an iPhone. Add sms to an out message to make it green:

Shane: can't check, the signal in this rink is terrible

Shane: these are going as texts. it's like 2009 in here

<p class="msg out sms"><span class="hide"><em>Shane:</em> </span>can't check, the signal in this rink is terrible</p>
<p class="msg out sms"><span class="hide"><em>Shane:</em> </span>these are going as texts. it's like 2009 in here</p>

Only sent messages turn green, the same as on a real phone. Messages from someone without an iPhone are grey like everyone else's, so they don't need anything extra.

Tapbacks in a Group Chat

When more than one person reacts to the same message, iMessage stacks the tapbacks on the corner, overlapping, with the first one at the front. Put the imsg-tap spans one after another at the end of the message. The first one gets the tail, and each one after it tucks in behind, a bit further along the bubble:

Scott:

reminder that nobody is letting Ilya run the drills again [Shane reacted 😂] [Hayden reacted ‼️] [Ryan reacted 👍]

Shane: the kids loved it though [Ilya reacted ❤️] [Scott reacted 👎]

<p class="who">Scott<span class="hide">:</span></p>
<p class="msg in tapped">reminder that nobody is letting Ilya run the drills again<span class="imsg-tap me"><span class="hide"> [Shane reacted </span>😂<span class="hide">]</span></span><span class="imsg-tap"><span class="hide"> [Hayden reacted </span>‼️<span class="hide">]</span></span><span class="imsg-tap"><span class="hide"> [Ryan reacted </span>👍<span class="hide">]</span></span></p>
<p class="msg out tapped"><span class="hide"><em>Shane:</em> </span>the kids loved it though<span class="imsg-tap"><span class="hide"> [Ilya reacted </span>❤️<span class="hide">]</span></span><span class="imsg-tap"><span class="hide"> [Scott reacted </span>👎<span class="hide">]</span></span></p>
More about stacked tapbacks
  • Each person gets their own imsg-tap span, with their own emoji and their own hide text saying who reacted. Up to four stack neatly.
  • If your point-of-view character reacted, put their imsg-tap me first, so the blue one is at the front, like it is on a real phone.

With the workskin off, it reads:

Scott:

reminder that nobody is letting Ilya run the drills again [Shane reacted 😂] [Hayden reacted ‼️] [Ryan reacted 👍]

Shane: the kids loved it though [Ilya reacted ❤️] [Scott reacted 👎]
