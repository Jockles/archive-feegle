This chapter goes through the CSS for the classic tweets in the last chapter. The module has two parts: the tweet (twc) and the timeline it can sit in (twc-feed), with the 2012-15 switch (tw2012) after them.

Getting the CSS

The Classic Twitter CSS is here: jockles.com/fic/megaskin/css/twitter-classic.css. It needs the core CSS too, so paste the core into your work skin first and this underneath it. It doesn't need the Twitter/X module.

How the Module is Laid Out

The usual order: the tweet, an opened tweet, the timeline, then the 2012-15 switch, the Dark and Auto themes, and Icons at the end. Every rule starts with .twc or .twc-feed, so even though the parts inside have the same names as Twitter/X's (tw-top, tw-stats and so on), the two modules never get in each other's way.

The Picture Column

#workskin .twc {
  position: relative;
  padding: 0.7em 1em 0.55em 4.75em;
}

#workskin .twc .tw-pfp {
  position: absolute;
  top: 0.75em;
  left: 1em;
  width: 48px;
  height: 48px;
  border-radius: 50%;
}

The big left padding on the tweet leaves an empty column down the side, and the picture is pulled out of the line with position: absolute and pinned into it. Everything else in the tweet - the label, the name line, the words and the buttons - lines up in the space beside it, with no extra boxes needed. An opened tweet (big) takes the padding away again and gives the name line its own padding instead, so the picture sits beside the name and the words run the whole width underneath.

The 2012-15 Switch

#workskin .twc.tw2012 .tw-pfp,
#workskin .twc-feed.tw2012 .tw-pfp,
#workskin .twc-feed.tw2012 .tw-me { border-radius: 5px; }

#workskin .twc.tw2012 .tw-time,
#workskin .twc-feed.tw2012 .tw-time { position: absolute; top: 0.85em; right: 1em; font-size: 0.85em; }

Every 2012-15 rule names both .twc.tw2012 and .twc-feed.tw2012, so the switch works on a tweet on its own or on a whole timeline. The square pictures are the same circles with a smaller border-radius, and the time is pinned to the top right corner the same way the picture is pinned to the left. The star, the curved arrow and the three dots are swapped in by the Icons section, which changes the pictures behind the same icon spans.

Dark and Auto Themes

Night mode is #15202b for the background, white for the text, #8899a6 for grey and #38444d for the lines. The blue 2012-15 bar stays blue in every theme. The auto theme is the dark rules again inside @media (prefers-color-scheme: dark), so change a colour in both places.

Taking Parts Out

  • The timeline: everything starting .twc-feed.
  • Opened tweets: the rules with .big, tw-date, tw-counts and twc-foot.
  • 2012-15: everything with tw2012 in it.
