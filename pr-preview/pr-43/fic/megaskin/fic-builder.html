Megaskin by Jockles

Fic Builder

This is a WYSIWYG (what you see is what you get) helper for building the skinned HTML for your chats: add your characters, type the messages, and pick the extras you want. The preview shows it with the real megaskin as you go, and when you're done you can copy all the HTML in one go. It's only a shortcut. Everything it makes is the same HTML the tutorial teaches, so you can still change any of it by hand afterwards, and you don't have to use it at all if you don't want to, or if it ever breaks.

Nothing you type leaves your browser. Your work is kept in this browser until you clear it, and you can download it as files to carry on somewhere else.

Download your files often! If you clear your browser's cache or history without downloading your HTML and CSS first, everything you've made here is gone for good. Browsers can also crash or tidy up their storage on their own, so download a copy of anything you're working on regularly.

1. Cast

Everyone who sends a message. One-offs are typed straight into the chat. Profiles keep a character the same in every chat and every app, and the profile CSS goes into your work skin (see Character Profiles). The example profiles are already in the skin.

For an easier way to make a full character profile, with every option and a preview of it in every app, use the Profile Maker. Then paste or open its CSS here with "+ Add existing profiles".

Made profiles before, here or with the Profile Maker? Paste their CSS here (one profile or lots). If you have them saved as a CSS file, you can upload the file with the button below instead. They're added to the cast ready to use or edit, and they only go in the CSS to copy if you change them.
