Chapter 1: Getting Started, Sources and Credits

Welcome to the megaskin, my complete socmed fic workskin of doom.

This workskin aims to make it as easy as possible to have multiple types of digital media stuff in one fic - different kinds of chats, different kinds of social media posts, and inline translations that work in all of them.

Ilya - iMessage

Today 9:41 PM

Ilya: hey are you up

Shane: no, I'm sleeping

Ilya: I need pictures gimme gimme

Read 9:43 PM

The whole system is designed to be modular - you can add or remove whatever sections of the skin that are relevant to you, up to and including using the whole thing in a single fic that incorporates many types of digital content from around the internet.

Each chapter explains how to use the HTML of that particular module, how to create the various kinds of posts/containers/whatever for that platform, and what each bit of the code is doing so that you can make your own edits where required. It will then be followed by a chapter that explains the CSS belonging to that module, including a link to the pastebin that has everything you need to stick in your own skin.

At the very end, there is a link to the pastebin that has the full megaskin (used by this fic) so that you can choose to just shove the whole lot in if you don't want to be picky.

About the pictures. The pictures in the examples are a mix of stock photos and photos from my own collection, which are hosted on my tumblr. All of the cat pictures are of my own cat. If a stock photo is broken, it's probably been taken down from wherever it was hosted.

Why this exists. I made this after several work skin newbies asked me how to combine multiple work skins in a complex fic with lots of different social media formats, since AO3 only lets a work use one skin at a time. I wanted something I could simply hand to them, so that it all just works: one skin that covers every format, with one tutorial to go with it.

Getting started

Setting up your work

First you will have to create the workskin for yourself in your own workskin lists. I have a megaskin for myself that has every module, and if you pick only a few modules I'd recommend reminding yourself which ones you've added in the description.

When you create the fic itself, open the HTML editor in AO3 (the HTML tab, not Rich Text) and paste the code in. Then select the work skin under Select Work Skin on the posting form.

My advice: keep hold of your HTML in a code editor (there are plenty of free ones out there) rather than in the document you write your fic in. Code editors colour in the tags and keep everything lined up, which makes your HTML much easier to read and fix. Or, if you'd rather keep it all together, add the HTML in at the end, separately from your regular rich-text prose - blocks of HTML sitting between normal rich-text prose won't paste into the HTML editor the way you want.

Do the pasting in the HTML tab and switch to Rich Text only at your own risk: Rich Text can quietly strip or rearrange the classes the skin depends on and then it breaks and you're sad.

Whenever a snippet says to put something "inside" another part, it goes between that part's opening and closing tags. (the words inside the <xx> and </xx>) Every chapter ends with a complete finished chat you can copy and edit, so you don't have to assemble the pieces yourself, but you should know enough at the end of each section to deconstruct it if you wish without breaking anything important.

One skin for everything, or one for each fic?

Some parts of the CSS contain places to put things like profile pictures and backgrounds that are likely to be fic specific, so you can choose if you want to have one skin and lots and lots of images defined, or have a different skin for each fic.

Some quirks of the code that you'll notice

One thing AO3 does when you paste HTML: if it finds words, spans or pictures sitting loose inside a <div>, it wraps them in a paragraph and turns the line breaks between them into <br /> tags, which can knock a chat out of shape. All of the code in the html examples is written so that never happens - anything that holds text or pictures directly is a <p> - so what you see when you inspect an example on the page should be exactly the code shown under it. If you write your own pieces, do the same. (AO3 also adds rel="nofollow" to every link, which is normal and doesn't change anything.)

The class names all follow the same pattern too, so once you've learnt one app the rest feel familiar. Anything that only belongs to one app starts with that app's class - tw-name for a Twitter/X name, tb-header for the top of a Tumblr post, dc-time for a Discord timestamp - and the pieces every app shares have the same name everywhere: msg, in, out, who, pfp, hide, me, colour1 to colour10, the theme classes, wide and no-scroll.

Credits and sources

This work skin stands on the shoulders of the work skins and tutorials below, which I used as references and in many places adapted. Please visit them, leave kudos and comment to thank their creators, truly I could not have done it without their guidance and much greater css fuckery skills than mine:

Hover and Tap Translations

  • How To Change Text on AO3 When the Cursor is Hovering Over It (Or Clicked on Mobile) by La_Temperanza, archiveofourown.org/works/10957056. Swapping the text when the reader hovers or taps, the brackets that show when Creator's Style is off, and using a link so that tapping works on a phone are all based on this. In this skin every translation is written in the HTML, so no new CSS is needed for each one.

iMessage

  • How to Make iOS Text Messages on AO3 by CodenameCarrot and La_Temperanza, archiveofourown.org/works/6434845. The picture messages, typing dots and the hidden text for readers with the style switched off are based on this.

WhatsApp

  • WhatsApp group chat skin by orphan_account, archiveofourown.org/works/34229317. The table layout of the group header, the member list under the group name and the sender-name ideas come from this.
  • Whatsapp Work Skin Template /Revamped by worlds_end_valentine, archiveofourown.org/works/46531021. The group chat, reactions, header and per-chat background ideas come from this.
  • Those two WhatsApp skins are themselves inspired by Social Media Work Skin Template: Whatsapp by worlds_end_valentine (credited as etc_e_tal in the group chat skin), archiveofourown.org/works/31313318, and WhatsApp Skin by Azdaema Codes (Azdaema), archiveofourown.org/works/24273361, which are also worth a look.

Twitter/X

  • Twitter Work Skin Template by worlds_end_valentine, archiveofourown.org/works/47803507. The timestamp line, liked and reposted counts, labels, sensitive content warning, polls, picture and video tweets, scrollable thread, DM reactions, group DMs, voice messages and the scrollable DM window are based on this.

Instagram

  • Repository: Work Skins by gadaursan, archiveofourown.org/works/8631214. The Instagram post layout and the use of hidden text for emojis are based on this (it also has Twitter and non-iOS messaging skins).
  • Work Skin - Instagram Image Post by shysonata, archiveofourown.org/works/79674881. The Follow link, verified tick, stories ring, counts beside the buttons, overlapping “liked by” faces and clickable like and save buttons are inspired by this. The idea of using the details and summary tags to make clickable buttons is credited there to mystyrust's fic chat, is this real?.

Tumblr

  • How to Make Tumblr posts on AO3 by phyripo (orphan_account), archiveofourown.org/works/11474979. The approach to reblog chains, ask boxes with the pointer, quote posts and chat posts comes from this.
  • Tumblr-style CSS Tweaks by Aposiopesis, archiveofourown.org/works/21099596. Improvements to reblogs and photosets, based on phyripo's guide.

Email

  • Gmail: How to insert Gmail emails in your fic by DemigodOfAgni, archiveofourown.org/works/53302357. The Gmail email layout, with its table headers and Reply buttons, is based on this.
  • Generic email: How to Mimic Email Windows by La_Temperanza, archiveofourown.org/works/7953412. The title bar, header lines, scrolling message body, attachments and Reply / Forward / Delete bar are based on this.

Discord

  • Discord Work Skin & Tutorial by BookKeep, archiveofourown.org/works/42027846. The Discord skin is mainly adapted from this. BookKeep's Discord user system - one class per character, carrying their picture through every message - was also a big part of what inspired me to make the character profiles in this skin, so a special thank you to them, both for the inspiration and for the framework that made it happen.
  • 2023 Discord Theme Workskin by TrojanTeapot, archiveofourown.org/works/46815217. A second Discord skin consulted alongside BookKeep's; it is itself inspired by Discord (Dark Theme) Work Skin Guide/Preview by Heterochromia_Mars.
