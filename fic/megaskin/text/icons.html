The Icons module is an optional extra. It swaps the little symbols in the other modules - the mic in the message box, the hearts and reblog arrows, the blue ticks and so on - for proper icons. Leave it out and every chat still works, with the symbols as text.

What It Does

Most of the buttons in the skin are typed symbols, like ♡ for a like or ⇄ for a reblog. They're fine, but they change from device to device, and some of them (like 🎤 for the mic) show up as colourful emoji when the real apps use plain outlines. The Icons module puts a picture over each one, so they look the same everywhere.

Light chats get black icons and dark chats get white ones, and they follow your theme- class like everything else. A few icons are always the same colour, whatever the theme:

  • WhatsApp's blue read ticks
  • the blue verified badges on Twitter/X and Instagram
  • Instagram's red liked heart
  • the round send and mic buttons in iMessage and WhatsApp

The pictures are hosted on squidge.org. If squidge is ever down, the icons won't show, and because the module hides the symbols underneath, those buttons will just be blank until it's back.

Every icon the skin uses is in this album on squidge.org, and you're welcome to use them - in your own skins, your own icons, wherever.

Getting the CSS

The Icons CSS is here: jockles.com/fic/megaskin/css/icons.css. It goes at the very end of your work skin, after the core and every app module you're using. It's already at the end of the full megaskin, so if you use that, you have it - cut it out (everything between its two MODULE lines) if you don't want it.

Which Symbols Change

Every example in this tutorial already has the right classes in it, so if you copied your HTML from here, there's nothing else to do. This is what changes in each app:

  • iMessage: the mic in the message box, and the blue send arrow.
  • WhatsApp: the back arrow, video and menu buttons at the top; the emoji, paperclip and camera in the message box; the green mic and send buttons; the blue read ticks; and the link symbol on link previews.
  • Twitter/X: the verified badge, and the play button on voice notes.
  • Instagram: the three dots, the verified badge, and the like, comment, repost, share and save buttons.
  • Tumblr: the save, share, reply, reblog and like buttons along the bottom.
  • Email: Gmail's star, reply, three dots and the little arrow by "to me", the Reply, Reply all and Forward buttons, and the paperclip, document and picture symbols on email window attachments.

The Tumblr checkmarks and Discord have their own pictures already, so the Icons module doesn't touch them.

Adding an Icon Yourself

An icon is a span with ic and the icon's name, with the symbol still inside it for readers who have the style turned off:

<span class="tb-icon ic ic-heart">&#9825;</span>

Keep the app's own class (tb-icon here) as well - that's what sizes and spaces it. The names are:

  • Black or white, depending on the theme: ic-back, ic-camera, ic-comment, ic-dropdown, ic-emoji, ic-forward, ic-heart, ic-menu (three dots up and down), ic-mic, ic-more (three dots across), ic-paperclip, ic-play, ic-reblog, ic-reply, ic-reply-all, ic-repost, ic-share, ic-share-up, ic-star, ic-video
  • Always the same colour: ic-read (blue double ticks), ic-verified (blue badge), ic-heart-red, ic-imsg-send, ic-wa-send, ic-wa-mic

How the CSS Works

#workskin .ic {
  display: inline-block;
  width: 1em;
  height: 1em;
  overflow: hidden;
  text-indent: -100em;
  text-align: left;
  white-space: nowrap;
  vertical-align: -0.15em;
  background-repeat: no-repeat;
  background-position: center;
  background-size: contain;
}

Every icon is a square the size of the text around it. text-indent: -100em pushes the symbol a long way off to the left, and overflow: hidden cuts it off, so all that's left is the picture, which background-size: contain fits into the square.

#workskin .ic.ic-heart { background-image: url(https://images.squidge.org/images/2026/11/15/heart-black.png); }
#workskin .theme-dark .ic.ic-heart { background-image: url(https://images.squidge.org/images/2026/11/15/heart-white.png); }

Each icon has a black line, then a white line for theme-dark, and the white line again inside @media (prefers-color-scheme: dark) for theme-auto. The coloured icons only have one line each.

The rest of the module is small fixes for particular spots:

  • WhatsApp's message box: the icons sit in table cells, so they get a set width.
  • WhatsApp's top bar: it's coloured in every theme, so its icons are always white.
  • Twitter/X voice notes: one you sent sits in a blue bubble, so its play button is white.
  • Instagram and Tumblr bookmarks: these are drawn with CSS in their own modules, so the Icons module rubs out the drawing before adding the picture.
  • Link previews and attachments: these symbols come from the CSS rather than the HTML, so the Icons module swaps them in the same place.

Taking Parts Out

Don't want one of the icons? Delete its lines (the black one, the dark one, and the one inside the @media block) and that symbol goes back to being text. To drop the whole thing, delete the module.
