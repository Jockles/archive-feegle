Megaskin by Jockles

Fic Builder

This is a WYSIWYG (what you see is what you get) helper for building the skinned HTML for your chats: add your characters, type the messages, and pick the extras you want. The preview shows it with the default megaskin as you go, and when you're done you can copy all the HTML in one go. It's only a shortcut. Everything it makes is the same HTML the tutorial teaches, so you can still change any of it by hand afterwards, and you don't have to use it at all if you don't want to, or if it ever breaks.

Nothing you type leaves your browser. Your work is kept in this browser until you clear it, and you can download it as files to carry on somewhere else.

Save your work often - either by downloading it or copying the code elsewhere! If you clear your browser's cache or history without saving your HTML and CSS first, everything you've made here is gone for good. Browsers can also crash or tidy up their storage on their own, so save a copy of anything you're working on regularly. There is no way to recover any lost work.

New here? 'Tutorial' walks you through making a simple text chat, step by step. 'Help text' shows a short explanation under every box. Without it, hover over or tap any ? to see the help for that box. You can have either one on, or both.

Your work 'Download' saves your work as files on your device. 'Open' a file to carry on from where you left off. The examples are the chats from the tutorial, to look at or change. 'Start a new one' clears everything for a blank page.

1. Cast 'Add a character' gives you a new box to fill in. You don't have to add everyone here first: anyone named in a chat's 'Type or paste messages' box is added for you. Press a character's name to fold their box up or open it again.

Everyone who sends a message. One-offs are typed straight into the chat. Profiles keep a character the same in every chat and every app, and the profile CSS goes into your work skin (see Character Profiles). The example profiles are already in the skin.

For an easier way to make a full character profile, with every option and a preview of it in every app, use the Profile Maker. Then paste or open its CSS here with "+ Add existing profiles".

Made profiles before, here or with the Profile Maker? Paste their CSS here (one profile or lots). If you have them saved as a CSS file, you can upload the file with the button below instead. They're added to the cast ready to use or edit, and they only go in the CSS to copy if you change them. Only character profiles can be opened or pasted here. Any changes made to the rest of the skin won't show in this preview, so test those in your own AO3 drafts.

2. Chats and posts

Each chat or post has its own settings, a list of messages (or tweets, or comments), and a box to type or paste lots of them at once.

Add: Each button adds a new, empty chat in that app. You can have as many chats as you like, and the arrows at the top of each chat move it up or down.

Preview This is how your chats look with the default megaskin. It changes as you type.

3. Copy 'Copy the HTML' copies the code for all your chats in one go, ready to paste. The 'Profile CSS' box only shows up if you've made or changed a profile. The tutorial explains where each one goes.

'Manually add profile' lets you paste the CSS for profiles you've made before straight into the 'Profile CSS' box, with no files to download or open. You can add any number of profiles at once, as long as each one is the whole profile, copied as it is. They're added to the cast, ready to use.

Paste the CSS for any number of profiles in this box, copied from the Profile Maker or your work skin. They're added to the cast. Any changes that you make to the profiles under 'Cast' will update this CSS.
