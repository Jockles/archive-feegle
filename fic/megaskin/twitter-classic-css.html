Chapter 11: Classic Twitter CSS

This chapter goes through the CSS for the classic tweets in the last chapter. There are two modules, one for each era, and each has two parts: the tweet (twc16 or twc12) and the timeline it can sit in (twc16-feed or twc12-feed).

11.1 Getting the CSS

The Classic Twitter CSS is in two files, one for each module:

  • 2016-19: jockles.com/fic/megaskin/css/twitter-classic-2016.css
  • 2012-15: jockles.com/fic/megaskin/css/twitter-classic-2012.css

Each needs the core CSS too, so paste the core into your work skin first and the module (or both) underneath it. Neither needs the Twitter/X module or the other classic one.

11.2 How the Modules are Laid Out

Both modules are in the same order: the tweet, an opened tweet, the timeline, the Dark and Auto themes, and Icons at the end. Every rule starts with the module's own classes, so even though the parts inside have the same names as Twitter/X's (tw-top, tw-stats and so on), none of the three modules get in each other's way.

11.3 The Picture Column

#workskin .twc16 {
  position: relative;
  padding: 0.7em 1em 0.55em 4.75em;
}

#workskin .twc16 .tw-pfp {
  position: absolute;
  top: 0.75em;
  left: 1em;
  width: 48px;
  height: 48px;
  border-radius: 50%;
}

The big left padding on the tweet leaves an empty column down the side, and the picture is pulled out of the line with position: absolute and pinned into it. Everything else in the tweet - the label, the name line, the words and the buttons - lines up in the space beside it, with no extra boxes needed. An opened tweet (big) takes the padding away again and gives the name line its own padding instead, so the picture sits beside the name and the words run the whole width underneath.

11.4 What's Different in 2012-15

#workskin .twc12 .tw-pfp {
  border-radius: 5px;
}

#workskin .twc12 .tw-time { position: absolute; top: 0.85em; right: 1em; font-size: 0.85em; }

The twc12 module is the same layout with the older look built into it. The square pictures are the same picture box with a smaller border-radius, and the time is pinned to the top right corner the same way the picture is pinned to the left. The star, the curved arrow and the three dots are swapped in by its Icons section, which puts different pictures behind the same icon spans.

11.5 Dark and Auto Themes

Night mode is #15202b for the background, white for the text, #8899a6 for grey and #38444d for the lines. The blue 2012-15 bar stays blue in every theme. The auto theme is the dark rules again inside @media (prefers-color-scheme: dark), so change a colour in both places.

11.6 Taking Parts Out

  • The timeline: everything starting .twc16-feed or .twc12-feed.
  • Opened tweets: the rules with .big, tw-date, tw-counts and twc-foot.
  • The little arrow (2016-19): the rules with tw-more and ic-dropdown.
  • Details (2012-15): the tw-details rule.
